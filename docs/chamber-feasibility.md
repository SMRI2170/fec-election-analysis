# Issue #66 — 上院（Senate）比較の採否判断

**Issue:** [#66](https://github.com/SMRI2170/fec-election-analysis/issues/66)（親 [#52](https://github.com/SMRI2170/fec-election-analysis/issues/52)）

**判定: 上院比較は採用しない。研究は下院（House）に絞る。** 理由は本ノートに記す実測値に基づく。**このIssueは上院だけの研究版を作らない。**下院の916件・除外理由・凍結指標・4年分のSHA-256は**一切変更していない**。

## 1. なぜ判断が必要か

講義資料Rep1v1015.pdf p.5/8は、**州・上下院・年度**を分析要素の例として提示する。上下院を両方分析することは要求ではなく例示である。**上院を比較に足す価値と安全性を見積もったうえで、採否を記録する。**

## 3. 採用しなかった理由

1. **比較可能な母数が小さい。**4年で135レース、うち両党Primaryがあるのは**103件**（年26件前後）。本研究の設計（評価年より前の年だけを学習する年度外評価）では、検証年ごとの検証母数が年26件になり、**状態別の残差（[#63](https://github.com/SMRI2170/fec-election-analysis/issues/63)と同じ切り口）は1州1〜2件になって州別議論が成立しない**。年26件で2パラメータのモデルを評価しても、推定区間は広く、**下院916件で得た結論の検証には使えない**。
2. **分析単位が全く異なる。**上院は**州全体**の選挙で、1選挙あたりの二党票が下院地区の約9.5倍（表3）。「上下院を比較する」ことは、**議会の違いと選挙単位の違いを同時に変化させる**ことであり、差の原因を分離できない。下院地区の予備選挙得票率は州全体の支持率ではないのと同じ構造である。
3. **同一地区のペア比較ができない。**本Issueの要件は「同一地区の`paired`比較と**偽らない**」ことである。**上院に地区は存在しないため、原理的にペア比較が成立しない。**下院地区と上院レースを並べる比較は単位が違うため「ペア」と称することはできない。
4. **キーが不安定で、除外規則を別に写得ないといけない。**表1のとおり `DISTRICT` 列は任期ラベルで年により表記が揺れる。小計行の語彙も年により3種で、合計行も `total state votes:` である。**上院版の正規化器・除外台帳・監査をゼロから作る必要があり、既存の下院用処理をそのまま再利用できるわけではない。**
5. **特別選挙が毎年混入する。**終期未定のラベルが2018年`MN`・`MS`、2020年`GA`、2022年`CA`・`OK`に現れる。**同じ州が同じ年に2回の上院選挙を行う**（2020年GA）ため、州を単位とする比較は「州×年」というキーがそのままでは崩れる。
6. **6年任期により年度効果と議席効果が交絡する。**上院議席は3年ごとにクラスがずれるため、**同じ議席が連続年度で観測されない**。本研究が下院で論じている「年度ごとの平均差」（[#77](https://github.com/SMRI2170/fec-election-analysis/issues/77)）は上院では「当該年に回ってきた議席の集合」の違いとしてしか読めない。
7. **コストと締切の対比。**上院版には専用スクリプト・除外台帳・監査・専用CI・研究ノートが必要で、**11月3日17時の提出様式の整備に先に着手すべきP0作業が残っている**。採算が合わない。

## 4. 講義意図との整合

- 講義は「州・上下院・年度」を**分析要素の例**として示すものであり、**上院を分析する必要があるわけではない**。
- 本研究は**下院に限定した理由を明記する**ことで、標本選択の議論（[#57](https://github.com/SMRI2170/fec-election-analysis/issues/57)・[#63](https://github.com/SMRI2170/fec-election-analysis/issues/63)・[#65](https://github.com/SMRI2170/fec-election-analysis/issues/65)・[#77](https://github.com/SMRI2170/fec-election-analysis/issues/77)）と一体で**射程（適用可能範囲）を示す**。**上院を採らなかったこと自体が本研究の結論の一つ**であり、隠さない。
- なお、#14・#17で扱う**原票の州選管照合**は上院を含む別系統の作業であり、この判定とは独立している。

## 6. 限界

1. **この下調べは公式Excelの読取と数え上げであり、上院研究ではない。**上院で予測モデルを動かしていない。
2. **「両党にPrimary票がある」は数え上げの定義であり、採用条件を意味しない。**採用すればさらに除外が発生し、母数は**103件より小さく**なる。
3. **規模比9.5倍は4年の平均**であり、州ごとに大きく異なる（`CA`・`NY`など人口の大きい州はさらに大きい）。
4. **2016年の上院シートには任期ラベルが `S` しかなく、2018年以降と構造が異なる。**表1の表記揺れはこの差を反映している。
5. **この判定は本研究の母数と締切に依存する。**想定母数が大きく、かつ締切に余裕があれば判断は変わりうる。
