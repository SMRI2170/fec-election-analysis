# 年度外予測の誤差構造を分析する：916件のFEC原票に基づく追加実証（2026-10-17）

> **研究上の位置付け:** 提出レポートの中心となる追加実験（Issue #6）。実際にFEC公式2016・2018・2020・2022年ExcelをGitHub Actionsで再取得・正規化した**50州のVoting House916件**のうち、2018年241区、2020年237区、2022年238区を各年独立に年度外評価した。[公式4年ワークブック再取得・SHA-256検証・実分析のCIログ](https://github.com/SMRI2170/fec-election-analysis/actions/runs/39004069145)。
>
> この文書の数値は**合成テストケースではない**。各年のテスト選挙結果を説明変数や学習に入れず、予備選挙の共和党二党得票率だけを入力とした。計算された二党票優勢は**当選者の認証結果と常に同義ではない**。本分析は観測的・探索的で、投票行動の因果説明や全米の無作為推定ではない。

## 1. RQ1：単純なPrimary持越しに対する回帰の改善は広く確認できるか

|テスト年|テスト区数|定数平均MAE|Primary持越しMAE|線形回帰MAE|持越し比MAE削減|線形回帰が優位な区|州単位再標本化MAE改善幅95%区間|
|---|---:|---:|---:|---:|---:|---:|---|
|2018|241|0.132673|0.062852|**0.044157**|29.74%|154/241（63.9%）|**0.010063〜0.027636**|
|2020|237|0.139806|0.078389|**0.054936**|29.92%|153/237（64.6%）|**0.014447〜0.034840**|
|2022|238|0.140875|0.075042|**0.050168**|33.15%|162/238（68.1%）|**0.017960〜0.032158**|

定数平均は学習年のGeneral得票率平均、Primary持越しは予備選挙比率をそのまま本選挙予測とする規則。州再標本化は**同じ選挙区のPrimary持越し絶対誤差−線形回帰絶対誤差**を州単位で4,000回復元抽出した探索的95%分位区間（同じ州の区をまとめて抽出、固定seed）。州間の選択バイアスや時間依存性を消すものではなく、厳密な母集団信頼区間や統計学的な因果効果ではない。

**主張可能な結果:** 線形回帰の改善は、同じ2022年テスト238区のうち**162区**で観測され、一部の突出した大外れだけで平均差が生じたわけではない。2018・2020年にも改善が観測された。ただし**87/241、84/237、76/238区**では逆に線形回帰の誤差が大きかった。改善は全選挙区に一律ではない。

## 2. RQ2：平均MAEだけでは隠れる年度による一方向の偏り

符号付き残差を **予測したGeneral共和党二党得票率−実際の同得票率** と定義する。プラスはR得票比率を**過大予測**、マイナスは**過小予測**。

|未知テスト年|学習区数|切片|Primary係数（傾き）|符号付き残差平均|過大予測区／過小予測区|RMSE|
|---|---:|---:|---:|---:|---:|---:|
|2018|200|0.167320|0.671646|**+0.77 pt**|140 / 101|0.058396|
|2020|441|0.146765|0.703629|**−4.58 pt**|40 / 197|0.068186|
|2022|678|0.163362|0.702391|**+3.00 pt**|168 / 70|0.063242|

3年度とも係数は約0.67〜0.70（傾きが1より小さく切片が正）で、Primaryの極端な比率をGeneralでは中間に近付ける「縮小補正」の形で学習している。これは**統計的な写像の特徴**であり、個々の有権者が中道化したことを意味しない。

**新しい発見:** 2020年のモデルはR得票率を197/237区で過小予測し、2022年は168/238区で過大予測した。したがって、単に3年のMAEが0.04〜0.06の範囲にあることをもって「時間的に安定した予測」と主張できない。対象年や学習年の構成が異なるため、これを米国有権者の党派シフトの因果証拠とは扱わない。

2022年の予測誤差の中央値は**4.32ポイント**、90パーセンタイルは**9.94ポイント**、95パーセンタイルは**12.26ポイント**、99パーセンタイルは**18.27ポイント**。2022年の誤差上位5区の合計は、同年238区の**絶対誤差合計の7.51%**であり、最悪事例のみで研究の結論を代表させない。

## 3. RQ3：どのPrimary得票率帯で補正が役立つか（2022年）

後から閾値を最適化しないよう、事前に**0〜35%、35〜45%、45〜55%、55〜65%、65〜100%**と固定した区間で分析。比率帯はすべて**予備選挙だけで決まる**ため予測時に把握できる。ただし各区間の観測MAEや誤判定は本選挙後の事後診断である。

|共和党Primary二党得票率|2022年区数|線形回帰MAE|Primary持越しMAE|線形回帰の符号付き平均残差|Primary多数派とGeneral多数派が不一致|
|---|---:|---:|---:|---:|---:|
|0〜35%|67|0.051915|0.076873|+2.18 pt|0|
|35〜45%|21|0.050178|**0.043641**|+4.10 pt|0|
|45〜55%|33|0.055213|**0.049995**|+3.54 pt|**15**|
|55〜65%|30|**0.065247**|0.075175|+4.80 pt|**9**|
|65〜100%|87|**0.041706**|0.090668|+2.53 pt|0|

**最も大きいMAE改善が見られたのはPrimaryで共和党65%以上の87区:** 0.090668→0.041706（約**54.0%削減**）。一方で35〜45%と45〜55%では、Primary比率をそのまま使う方法の方がMAEが小さい。したがって、「回帰補正は常に有効」とはいえない。

**分類の失敗はPrimary 45〜65%の63区に集中:** 2022年の単純Primary多数派規則とGeneral多数派の不一致は、45〜55%で15区、55〜65%で9区の**合計24区**。それ以外175区は**0区**。これは**この選別済み2022年集合に限る観測事実**であり、将来の45〜65%地区を38.1%の確率で外すと一般化できない。テスト年の多数派区分はGeneralのR/D二党票に限り、公式当選者と常に同じではない。

また、2020年の65%以上の区では**線形0.046873／持越し0.042160**と回帰の方が悪い。2022年の比率帯での大きい改善を、時間を超えて確立した法則としては主張できない。

## 4. 実際に外した選挙区の「原因」はどこまで分かるか

[2022年誤差上位5区の州公式一次資料の検証状況](2022-error-case-studies.md)では、RI-02とMI-03のPrimary・General R/D票は地区全体を独立照合済み、OH-09はGeneral全地区／PrimaryはDefiance・Erie・Ottawaの3/8郡、OH-15はClark郡のみ、NH-01は民主党Primary全地区と共和党PrimaryのGoffstown町・Generalの2町のみ。**全5区が州原典と完全一致したわけではない**。20党×段階の監査台帳では地区全体11／部分9。これらは**票の信頼性チェック**であり、候補者人気・社会背景の因果メカニズムを識別するものではない。

2022年に誤差上位5区を**結果を見てから選んだ**ため、上位5区の候補者競争度等の違いを有意差検定して一般化することは避ける。将来の研究では、別の未使用年度を最初から固定し、候補者間競争・州選挙制度・人口構成などが性能に及ぼす影響を独立に検証する必要がある。

## 5. 結論とレポート向けの主張

1. **有効性**：Primary比率の持越しより1変数の線形補正がMAEを約30%減らす年度外評価を3回再現。ただし2022年では**76区で逆転**する。
2. **条件依存性**：2022年はPrimaryでR65%以上の場合に補正効果が大きく、R35〜55%では単純持越しが相対的に良い。
3. **時間的な不安定性**：2020年は共和党得票率を平均4.58ポイント過小、2022年は3.00ポイント過大予測。**平均MAEに加え符号付き偏りを報告すべき**。
4. **信頼性・限界**：標本は1,756報告グループ中の採用916件に限り、年度別の州・選挙区網羅率が不均一。州単位区間は探索的診断であり、Primary/Generalの異なる投票者集合、事後選択、州制度の未対応が残る。
5. **再現性**：候補者票・党小計の検証、公式Excelの4ファイルSHA-256の固定、テスト年以前のみの学習、出典を明記した検算とpytest＋GitHub Actionsで再実行できる。
