# Issue #54 — 凍結プロトコルによる2024年評価の試行と終了記録

**Issue:** [#54](https://github.com/SMRI2170/fec-election-analysis/issues/54)　**依存:** [#53](https://github.com/SMRI2170/fec-election-analysis/issues/53)（評価計画の凍結、完了済み）

**結論（実測）: 評価は実行できなかった。理由は出典が未公開であることである。** 凍結した手順をそのまま走らせ、**値が1つも算出されない**ことを確認した。**代替値で埋めず、理由を記録して終了する。**

## 1. 何をしたか

[#53](https://github.com/SMRI2170/fec-election-analysis/issues/53) が固定した手順（`configs/frozen-2024-evaluation.json`）と**その3段階のパイプライン**を実装し、実行した。

| 段階 | スクリプト | 実測の結果 |
| --- | --- | --- |
| 1. 出典の取得 | `scripts/download_fec_2024.py` | **取得失敗。** 2024年版の版ページがHTTP 404。記録 `data/sources/fec2024_publication.json` に理由を残す（終了コード2） |
| 2. 正規化 | `scripts/normalize_fec_2024.py` | **実行せず。** 出典がないため正規化を開始しない（終了コード2、出力ファイルは書かない） |
| 3. 評価 | `scripts/evaluate_frozen_2024.py` | **実行せず。** 正規化済みの2024年ファイルがないため評価しない（終了コード2、**値は算出されない**） |

**3つのスクリプトはいずれも「出典がないのに値を出す」ことが構造的にできない。** 出典レコードの `status` が `available` でなければ正規化は始まらず、正規化済みファイルがなければ評価は始まらない。**2024年の出力が1つも生成されないことを実測で確認した**（`data/processed/` に2024年の生成物は存在しない）。

**2016～2022年の凍結母集団916件、凍結済みバックテストの指標、2010～2022年の出典台帳は変更していない。** 2024年の出典記録は別のファイル `data/sources/fec2024_publication.json` に置いた。

## 2. 出典の所在確認（実測）

**資料の所在と版だけを確認し、2024年の党別票・勝敗・精度・地区別結果は見ていない。**

| 確認項目 | 2026-10-25 の実測 |
| --- | --- |
| FECカタログページ | HTTP 200（37,667バイト）。双年刊「Federal Elections」の版のリンクは**2022年が最新**で、2024年の記載はない |
| 2024年版のページ | `…/federal-elections-2024/` は **HTTP 404**。別slug（`election-and-voting-information` 配下、`federal-elections-2024-results`、`federalelections2024`）もすべて **HTTP 404** |
| 2024年のExcel | `https://www.fec.gov/documents/6900/federalelections2024.xlsx` は **HTTP 404** |

**出典は未公開である。**

## 3. 代替案を検討したが採用しなかった

| 代替案 | 採否 | 理由 |
| --- | --- | --- |
| 2024年大統領一般選挙の公式結果（PDF・Excel） | **採用しない** | 大統領選挙の結果であり、PrimaryとGeneralの州別・地区別の**下院**結果が揃った形式ではない。本評価の単位と一致しない |
| 2024年上院選挙管理委員会の候補者一覧（`2024congressgecands.xlsx`） | **採用しない** | 候補者の一覧であって得票結果ではない。目的変数が入らない |
| FECの選挙結果の公開API | **採用しない** | 凍結計画で出典を「双年刊Federal Elections」と定めており、**出典の付け替えは禁止操作**に該当する。APIは州別の集計形式で、Primaryの票構成が本評価の単位と一致しない |
| 州選管の一次資料から下院結果を自作 | **採用しない** | 州ごとに形式・単位・党帰属の扱いが異なり、**除外カテゴリを事後に追加することになる**ため凍結計画の禁止操作に該当する |

**いずれも「計画どおりに実行できない」場合として、理由と代替案を記録して終了する扱いに該当し、**値を作らない**。

## 4. 確認できたこと・確認できていないこと

**確認できたこと（実測）**

1. **2024年の出典は未公開**であり、2024年の年度外評価は現時点では実行できない。
2. **パイプラインは出典なしで値を出しない。** 3段階すべてが停止し、終了コード2と理由の記録に収束する。
3. **凍結計画の検査は通る。** 文書と設定の一致、凍結コミットの存在と祖先性、出典台帳から2024年が漏れていないこと、がすべてCIで検査できる。
4. **評価部分は合成データで動作する。** `tests/test_frozen_2024.py` は合成の母集団と2024年の代理データで全工程を実行し、凍結された指標（MAE・二乗平均平方根・95分位・分類正解率・Brier・州単位ブートストラップ）を計算することを確認している。**これは実行可能性の検査であって、実世界の結果ではない。**

**確認できていないこと**

1. **2024年の性能そのもの。** 何も算出していない。
2. **2024年刊物のシート構成。** 2016～2022年版は「US House Results by State」というシート名の下院結果シートを1つ持つが、2024年版が同じ形式かは**未検証**。取得時に記録する。
3. **2024年の母集団規模と除外内訳。** 件数は事前に不明と宣言したとおり。
4. **2024年の制度差**（区割変更・特別選挙・無対立・順位付選択）。

## 5. 探索的・確認的な扱い

- **本Issueで主張する確認的な結果はひとつもない。** 2024年の結果は存在しないため、確認的な主張は**不可能**である。
- **凍結計画の主比較は、2024年の出典が公開され、計画どおりに実行された場合に限り確認的になる。** その条件はまだ満たされていない。
- **ブートストラップ区間は、2024年の評価を将来実施しても探索的**である（評価対象は無作為抽出の標本ではない）。
- **出典が未公開である事実は確認的な事実である。** ただしこれは予測精度の話ではなく、**評価の実行可能性**についての記述である。

## 6. 出典が公開されたら完了するには

```bash
python scripts/download_fec_2024.py              # 出典・SHA-256・シート名を取得時に記録
python scripts/normalize_fec_2024.py --writein-policy attribute
python scripts/evaluate_frozen_2024.py --assert-frozen-config
```

- 出典の記録は `data/sources/fec2024_publication.json` に書かれる。**正規化之前に、シート名と列見出し行だけが記録され、得票表は解析されない**（凍結の取得順序）。
- 2024年の正規化結果は `data/processed/elections_2024.csv` に**別ファイルで**出る。**凍結済みの `elections.csv`（916件）は上書きされない。**
- 評価は**凍結された設定だけ**から実行され、設定が変わったら `scripts/frozen_2024_protocol.py --check` が設定と文書の不一致を検出する。
- **結果が改善しなかった場合も、それはそのまま報告する。** 凍結_protocol を作り直さない。

## 7. 限界

1. **2024年の評価未実施**である。**本Issueは「評価の実行可能性の確認と終了記録」に過ぎない。**
2. **凍結計画の除外カテゴリは2016～2022年で開発した**ものであり、2024年の制度差に完全には対応していない可能性がある。**固定後に変更はしない**（変更すれば2024年の結果は探索的になる）。
3. **2024年のシート構成は未検証**であり、形式が違えば正規化は停止する（`house_sheet` の照合で検出する）。
4. **代替案を評価していない。** 出典の付け替えは凍結計画の禁止操作であるため、代替案の検討は記録にとどめた。
5. **母集団は非無作為**であり、州単位の不確実性は探索的である。
6. **本研究は新しい予測モデルを主張しない。**
