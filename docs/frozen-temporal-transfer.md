# Issue #77 — 学習済み補正式を固定して2020/2022年の時間的ずれを評価する

**Issue:** [#77](https://github.com/SMRI2170/fec-election-analysis/issues/77)

**研究の問い:** 年度外バックテストの平均符号付き残差が2020年−4.58ポイントから2022年+3.00ポイントへ逆転した。**年度の違いとモデルの再学習の違いを混ぜずに分離できるか。**

**答えは「分離できる」。**再学習の影響は平均+1.60ポイント、年度の影響は+5.98ポイントで、合計+7.58ポイントとして符号の逆転をちょうど説明し切る。**再学習は2022年の予測を事实上悪化させていた**（MAE 4.51ポイント→5.02ポイント）。**符号逆転の原因を特定したとは主張しない**（§5の限界）。

## 1. 設計（新しい年度結果を見る前に固定）

| 項目 | 内容 |
| --- | --- |
| 説明変数 | `P` = 予備選挙の共和党二党得票率 |
| 目的変数 | `G` = 本選挙の共和党二党得票率（**二党得票率**であり公式当選者ではない） |
| モデル | 1変数線形回帰 |
| 固定モデルの学習年 | **2016年200件＋2018年241件＝441件のみ** |
| 固定モデルの適用年 | 2020年237件・2022年238件（**係数・切片は変更しない**） |
| 比較対象のベースライン | 評価年より前の年すべて（2020年は441件、2022年は678件）＝現行の年度外バックテスト |
| 符号の約束 | 符号付き残差 ＝ 予測 − 実測（正は過大予測） |
| 指標 | MAE、`RMSE`、平均符号付き残差、過大/過小予測の区数、平均P、平均G、地区数n、州数 |
| 不確かさ | 州単位のクラスターブートストラップ（4000回・seed 20261025＋評価年）**探索的** |

**年度効果と再学習効果は別の表に示す。**固定モデルの残差変化は年度効果（モデルは変わらないため再学習では説明できない）、同一238区での予測値の差は再学習効果（年が変わらないため年度では説明できない）である。

**同じモデル**なので、平均符号付き残差の+5.98ポイントの変化は再学習では説明できない。年度効果の候補は、選択された選挙区・区割り・州構成・有権者集団・候補者確保の事情など**年度ごとの母集団の違い**である。**どの要素がどれだけ寄与したかは本Issueでは特定していない**（[#63](https://github.com/SMRI2170/fec-election-analysis/issues/63)の州構成の寄与分析とは別の切り口であり、州別の図表を再実装していない）。

### 表3：符号の逆転の分解（算術）

| 成分 | 値 | 説明 |
| --- | ---: | --- |
| 2020年 平均符号付き残差 | −4.58pt | 固定モデル（当年はベースラインと同じモデル） |
| 年度効果（固定モデルの2022−2020） | **+5.98pt** | モデルは不変。したがって再学習では説明できない |
| 再学習効果（拡張モデルの2022−固定モデルの2022） | **+1.60pt** | 同一238区・同一入力。切片が0.1468→0.1634へ上昇（+1.66pt）、傾きは0.7036→0.7024へ微減（−0.06pt） |
| 合計 | **+7.58pt** | −4.58pt → +3.00pt と一致 |

**再学習の悪化した面.** 2020年を学習に加えると2022年の予測は全区で+1.59ptだけ上がり、MAEは4.51ptから5.02ptへ**悪化した**（差+0.51pt、区間は0を除く）。原因は、2020年の学習年（平均P 0.4424、平均G 0.5038）が切片を持ち上げ、2022年のテスト年（平均P 0.5240、平均G 0.5014）より平均Pが高いため、切片がそのまま上振れしたからである。

## 3. 何が言えるか・何が言えないか

**言えること（探索的な記述）**

1. 既存バックテストの符号の逆転は、**年度差と再学習の差の両方**で説明される。再学習だけで説明，不代表は再学習である。
2. **再学習は2022年の精度を悪化させた。**現行の年度外バックテストの2022年MAE 5.02ptは、学習年を1年増やした結果であり、**学習窓の選び方に依存している**。
3. 固定モデルは2020年と2022年で**過小予測から過大予測へ**転じている（過小197区→過大145区）。これはモデルが古くなった可能性を示す記述であり、**原因を特定したものではない**。

**言えないこと**

1. **符号の逆転の原因を特定したとは主張しない。**年度効果+5.98ptの内訳（選挙区構成・区割り・州構成・候補者・投票率）は本Issueでは分解していない。
2. **因果効果ではない。**比率は投票者集団の変化を記述するものであり、 支持変化の原因を同定したものではない。
3. **2022年は確認的な保留試験ではない。**先行Issueの探索で既に観察済みである。
4. **2つの評価年で比較できる母集団ではない。**選択された選挙区・区割り・州構成が異なる（2020年237区・37州、2022年238区・36州）。
5. **FECのExcelは選挙後公刊**であり、当時の選挙前利用可能性は検証していない。
6. **本Issueは新しい予測モデルを主張しない。**既存のパイプラインの診断である。

## 4. 再実行手順

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests/test_frozen_temporal_transfer.py
python scripts/download_fec.py --years 2016 2018 2020 2022
python scripts/normalize_fec.py --years 2016 2018 2020 2022 --writein-policy attribute
python scripts/run_backtests.py --input data/processed/elections.csv --test-years 2018 2020 2022
python scripts/verify_reproducibility.py
python scripts/evaluate_frozen_temporal_transfer.py --assert-baseline
```

`--assert-baseline` は現行バックテストの2022年**MAE 0.0502**と**平均符号付き残差+0.0300**を再計算し、 凍結済みの916件も検証する（不一致なら例外で停止）。

出力はGit管理外の `data/processed/frozen_transfer/` 配下：`frozen_temporal_transfer.csv`（年×モデルの要約）、`frozen_temporal_transfer_paired.csv`（同一区での比較）、`frozen_temporal_transfer_districts.csv`（区ごとの予測と残差）、`frozen_temporal_transfer.json`（係数・分解・メタ情報）。**区ごとの明細は公開リポジトリに置かない。**

## 5. 限界

1. **単一変数モデル**の診断であり、候補者数など他の変数を統制していない。状態は本文の他の分析と同じ（[#59](https://github.com/SMRI2170/fec-election-analysis/issues/59)・[#60](https://github.com/SMRI2170/fec-election-analysis/issues/60)）。
2. **固定モデルの係数は1通りだけ**を試した。別の学習窓・別のモデル形を探索していない。
3. **州単位ブートストラップの区間は探索的**であり、非無作為な選択集合に依存する。
4. **母集団は非無作為**（採用率が年・州で異なる、[#57](https://github.com/SMRI2170/fec-election-analysis/issues/57)）。
5. **分割は算術的な分解**であり、因果的な分解ではない。
6. **本Issueは本報告の主張を支える追加証拠であり、符号逆転の原因を特定したものではない。**
