
# 予備選挙に基づく本選挙予測 — 年度外評価（Issue #4）

検証日: 2026-10-15  
データ: FEC Federal Elections 2016, 2018, 2020, 2022（US House Results by State）  
再実行記録: [GitHub Actions FEC source audit](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38687520194)

## 仮説と比較の狙い

予備選挙の共和党得票比率が本選挙の二大政党得票比率と関連するかを検証する。**回帰・分類モデルが単純な規則よりも十分優れているか**を対照実験で調べる。

比較可能と判定したレコードは、2016年169、2018年197、2020年188、2022年186、計740。州制度が未検証なデータ、無対立、得票集計不整合などは除外した。**全米すべての選挙の代表標本ではない。**

使用変数:
- \(P = R_{primary}/(R_{primary}+D_{primary})\)
- \(G = R_{general}/(R_{general}+D_{general})\)
- 二大政党に限定した共和党勝敗: \(G>0.5\)

PrimaryとGeneralで投票者集合が異なり、Pを支持率と解釈することはできない。目的は関連性・予測可能性の評価であり因果効果の推定ではない。

## 評価方法

\`scripts/run_backtests.py\` は、**2018年を2016年で、2020年を2016/2018年で、2022年を2016/2018/2020年で予測**する。未来年度を訓練に使用しないことをユニットテストでも確認する。

得票率回帰: mean-share dummy、Primary比率そのもの（identity）、linear regression。すべてMAEで比較（**小さいほど良い**）。

勝敗分類: 最頻クラスdummy、Primary比率が0.5超なら共和党勝利とする規則、logistic regression。accuracy（**大きいほど良い**）、確率出力のあるモデルについてはBrier score（**小さいほど良い**）で比較する。

## 考察（検証できた範囲）

1. 線形回帰は、全3年度で平均値ダミー・Primary比率の単純持越しよりもMAEが小さい。
2. **分類では、より複雑なロジスティック回帰が常に優れるわけではない。** 2022年の単純多数派規則は90.86%、ロジスティック回帰は84.95%だった。一方2020年は逆転した。
3. 同じ正解率でも確率予測の質は異なるため、ロジスティックモデルにはBrier scoreを併記した。

### 解釈の制約と後続課題

- データ除外が多く、予測の難しい州や選挙区が外れている可能性がある。精度を全米の選挙に一般化できない。
- 2022年を繰り返し見てモデルを選択すると研究上のテスト漏洩を起こし得る。以後の改良は探索的解析として区別する。
- 正解率の差は、有意差検定や信頼区間をまだ実施していない。差の原因が投票行動・州制度・モデル正則化のいずれかは確定していない。
- 選挙区ごとの重複・区割り変更・複数の選挙制度の影響の詳細検証は未完了。
- 誤予測の地域・得票差・除外条件の感度分析はIssue #5で扱う。
