# Issue #61 — 非線形比較の事前固定（評価プロトコル）

**Issue:** [#61](https://github.com/SMRI2170/fec-election-analysis/issues/61)（親 [#51](https://github.com/SMRI2170/fec-election-analysis/issues/51)）

**このIssueは実験の設定だけを固定する。**比較の実行と結果の公開は[#62](https://github.com/SMRI2170/fec-election-analysis/issues/62)が行う。**このIssueではどのモデルも実行しておらず、結果の数値も記載しない。**設定は評価年を1回も読む前に確定させた（事前登録）。

**目的:** 予備選挙の二党得票率から本選挙の二党得票率を予測するモデルの**形**（定数・持越し・線形・多項式・スプライン）を、同一の入力・同一の出力条件で比較するための手順を先に固定する。固定の目的は、**2022年の結果を見て有利なモデルを選ぶ経路を構造的に塞ぐこと**である。

## 1. 入力と母数

| 項目 | 固定値 |
| --- | --- |
| 母数 | 凍結済みの50州Voting House **916件**（2016=200／2018=241／2020=237／2022=238） |
| 説明変数 | `primary_rep_share`（予備選挙の共和党二党得票率） |
| 目的変数 | `general_rep_share`（本選挙の共和党二党得票率） |
| 目的変数の解釈 | **二党得票率**であり、公式当選者ではない |
| 同率 | 除外しない。本選挙の得票率がちょうど0.5の選挙区も有効な回帰の観測値として扱う |
| 入力ファイル | `data/processed/elections.csv` |

説明変数1変量だけを比较する。#59の候補者特徴量は別のIssue（[#60](https://github.com/SMRI2170/fec-election-analysis/issues/60)）で別の比較として扱い、**この比較のモデル群には混ぜない。**

## 2. 比較対象のモデル（5個・固定）

| 名称 | 族 | 内容 | 固定した値 | 学習 |
| --- | --- | --- | --- | --- |
| `constant-mean` | 定数 | 学習年の目的変数の平均 | なし | する |
| `primary-carryover` | 恒等 | 予備選挙の得票率をそのまま予測 | なし | しない |
| `linear` | 線形 | 目的変数を説明変数の一次式で回帰 | なし | する |
| `polynomial2-ridge` | 多項式＋ペナルティ | 二次多項式を標準化してから `Ridge` で回帰 | 次数2・`alpha`=1.0・標準化あり | する |
| `cubic-spline-ridge` | スプライン＋ペナルティ | **固定節点**の三次B-スプライン基底を標準化してから `Ridge` で回帰 | 次数3・節点5個・`alpha`=1.0・標準化あり | する |

- **固定節点**は `[0, 0.25, 0.5, 0.75, 1.0]`（得票率の範囲全体）であり、**データに依存しない**。基底は6列で、916件の母数に対して過大ではない。
- **標準化は学習年の平均と標準偏差だけで行い、検証年は標準化に含まれない。**検証年の情報が訓練に混ざる経路を作らないためである。
- `alpha`=1.0 は標準化した設計に対する固定値であり、探索は行わない。**この比較が測るのはモデル形の差であり、ハイパーパラメータ探索の成果ではない**（§8の限界）。
- 候補を5個に絞った理由は、**同程度の複雑さで比較できる範囲**を保つことにある。6個目以上（例：交互作用項、高次数多項式）は自由度裁定が不成文になり、事前固定の意味が薄れるため追加しない。追加する場合は本Issueの改訂ではなく**別バージョンのプロトコル**として扱う。

## 3. ハイパーパラメータの選択規則

- **選択: 固定値。探索・グリッド・選択ステップは行わない。**
- 万が一値を選ぶ必要が生じた場合のみ、**テスト年より前の年度だけ**を使う内側の時系列検証に限り、選択した値と理由を書き残してからテスト年を採点する。**この取り決めは実測結果を見てから適用してはならない。**
- 内側の検証年（実測結果によらず、規則として先に宣言）: 評価年2018年は**なし**、評価年2020年は2018年のみ、評価年2022年は2018年と2020年。
- **2018年の明示的な扱い:** 2018年より前の年度は2016年だけであり、1年分の学習年では年度外の検証分割を作れない。**したがって2018年は固定値のみを用い、これを「年度外検証」と呼わない。**この扱いは設定JSONの `note_for_2018` に明記している。

## 4. 評価の固定条件

| 項目 | 固定値 |
| --- | --- |
| 評価年 | 2018・2020・2022 |
| 学習年の規則 | **評価年より前の年度の母数すべて**（外挿はしない） |
| 予測の範囲外処理 | 範囲外予測は `clip(0, 1)` してから採点する（得票率の範囲外は不可能なため） |
| 指標 | `MAE`・`RMSE`・絶対誤差の95パーセンタイル |
| 指標の単位 | **パーセントポイント**（得票率に100を乗じた値） |
| 主指標 | `MAE` |
| 比較の基準 | `linear`（同一の母数・同一の規則で既存バックテストと比べる） |
| ペア比較 | 地区ごとの絶対誤差の差を**州単位でブートストラップ**（10000回・`seed` 20261025・95パーセンタイル区間） |
| ブートストラップの単位を州にする理由 | 同一州の地区は選挙制度と候補者プールを共有し、独立ではないため |
| 2022年の位置づけ | 2022年は既に先行Issueの探索に使用済みであり、**独立した確認的検証ではない**。探索的な年度として報告する |

## 5. 後知恵の入口を塞ぐ構造

1. **評価計画（`EvaluationPlan`）が値オブジェクトで固定される.** 評価年が決まると、学習年・内側の検証年・モデル群・指標・`clip`・ブートストラップ設定が一意に決まり、あとから書き換えられない。
2. **学習行には評価年が入らない.** `fitting_rows()` は評価年未満の年度だけを返し、万一評価年を含む場合は例外を投げる。
3. **チューニング段階はラベル列を拒否する.** `assert_no_label_access()` は、チューニング段階に目的変数の列（または他のラベル列）が現れた場合に `LabelAccessError` を投げる。評価段階では目的変数を読む（採点する）ので拒否しない。
4. **設定にチューニングの入口を残さない.** 設定JSONを走査して、`tuned`・`selected`・`search`・`grid`・`best`・`chosen` 之类的キー名を持つ項目がないことをテストで確認する。設定内のハイパーパラメータは**年ごとの上書きを持たない定数**である。
5. **決定論.** 固定節点と固定乱数により、同じ入力からは同じ結果が出る。設計行列の変換も入力データに依存しない。

## 6. 設定JSONの項目

`configs/nonlinear-comparison.json`（コミット対象、Git管理外の生成物ではない）

| セクション | 内容 |
| --- | --- |
| `protocol_version` / `frozen_at` / `issue` | バージョン・固定日・対応Issue |
| `data` | 入力・母数・説明変数・目的変数・同率の扱い・**チューニングで禁止する列の一覧** |
| `models` | 5モデルそれぞれの族・説明・固定ハイパーパラメータ・学習の有無 |
| `evaluation` | 評価年・学習年の規則・`clip`・指標・単位・基準モデル・ペア比較・ブートストラップ（反復・`seed`・単位）・2022の位置づけ |
| `hyperparameters` | 選択規則・固定値の理由・内側の検証年の表・2018年の注記・標準化の範囲 |
| `reporting_rules` | 結果の報告条件（劣る結果も必ず出す、件数と学習年を必ず添える、2022を確証的検証と書かない、設定の変更は別PR） |

## 7. 再現手順


比較の実行（#62で追加するスクリプト）は、本Issueの `scripts/nonlinear_protocol.py` の計画オブジェクトから設定を読み、**評価年ごとに同じ計画で**全モデルを採点する。

## 8. 限界

1. **ハイパーパラメータを探索していないため、比較はモデル形の比較である。**`alpha`=1.0が最適であるとは主張しない。ハイパーパラメータ探索を比較する研究は別の課題として扱う。
2. **固定節点のスプラインは得票率の範囲全体に固定している。**端点付近の举動は節点配置に依存し、これは事前に宣言した選択である。
3. **説明変数は1変数だけ**である。#59の候補者特徴量との組み合わせは別の比較であり、このプロトコルの外にある。
4. **2022年は探索済みの年**であり、比較結果を確証的な検証として Presentsできない。
5. **母集団は非無作為**（採用率が年・州で異なる）。
6. **このIssueは結果を算出していない。**この段階ではモデルの優劣を主張しない。**本研究は新しい予測アルゴリズムを主張しない。**
