# Issue #62 — 予備選挙得票率から本選挙得票率を予測するモデルの形を比較する

**Issue:** [#62](https://github.com/SMRI2170/fec-election-analysis/issues/62)（親 [#51](https://github.com/SMRI2170/fec-election-analysis/issues/51)）　**依存:** [#61](https://github.com/SMRI2170/fec-election-analysis/issues/61)（比較設定の事前固定）

**研究の問い:** 予備選挙の共和党二党得票率（P）から本選挙の共和党二党得票率（G）を予測するとき、**線形より複雑なモデルに安定した改善はあるか。**

**結論（実測）: ない。5候補を3評価年で比較した結果、複雑モデルはどの年も一貫して改善せず、2018年には線形反而悪化した。** 線形回帰1本の単純さが正当であり、**「複雑なモデルは不要」という所見を積極的な研究結果として採用する**。改善は最大0.19ポイントで、符号は年ごとに反転し、2022年では差がほぼ0である。

## 1. 比較設定は事前に固定されている

**このIssueでは設定を決めずに、設定に従った実行だけを行う。** モデル・次数・節点・ハイパーパラメータ・評価年・0〜1への丸め・メトリック・ブートストラップ設定は[#61](https://github.com/SMRI2170/fec-election-analysis/issues/61) が `configs/nonlinear-comparison.json` に凍結したものをそのまま読む（プロトコル版1.0、凍結日 2026-10-25）。**このIssueでは設定ファイルを編集していない。** ハイパーパラメータの探索・グリッド・内側検証による選択は**一度も行っていない**。

| モデル | 形 | 適合 | 説明 |
| --- | --- | --- | --- |
| `constant-mean` | 定数 | する | 学習年の目的の平均 |
| `primary-carryover` | 恒等 | **しない** | Pをそのまま予測に使う |
| `linear` | 線形 | する | Pの通常最小二乗（**参照モデル**） |
| `polynomial2-ridge` | 2次多項式＋Ridge | する | α=1.0、標準化あり |
| `cubic-spline-ridge` | 3次Bスプライン＋Ridge | する | 節点[0, 0.25, 0.5, 0.75, 1]固定、α=1.0、標準化あり |

- 5モデルとも**説明変数はPの1個だけ**。評価年・学習年・0〜1への丸め・メトリックの条件は同一。
- **2022年を最適化に使わない。** 2022年の結果でモデルを選ぶことは行わない。上記の5モデルは評価前に固定済みである。
- **2018年の設定は未定義にならない。** 2018年の前にあるのは2016年だけなので、内側の時系列検証は**できない**（`inner_validation_years` は空）。固定値を使うことを明示しており、これを「年度外検証」と称していない。
- **参照モデルの線形回帰は凍結済みバックテストと厳密に一致する**（下記、`--assert-baseline` で自動検査、許容差1e-12）。
- 説明側の列に本選挙の列は含まれないため、後知恵の経路は構造上存在しない。`tests/test_nonlinear_primary.py` は2022年の目的値を並べ替えても予測が変わらないことを検査する。

- 凍結母集団**916件**（2016: 200 / 2018: 241 / 2020: 237 / 2022: 238）。**母集団・除外理由・凍結基準値は変更していない。**

## 5. 何が言えるか・何が言えないか

### 言えること（探索的な記述）

1. **線形モデルへの上乗せに安定した改善はない。** 2次多項式と3次スプラインは2018年で**悪化し**（+0.07、+0.36ポイント）、2020年で**改善し**（−0.19、−0.13）、2022年では**ほぼ差がない**（−0.02、+0.03）。**符号が年ごとに反転する**ので、複雑モデルが常に線形よりよいと主張できない。
2. **改善の大きさは小さい。** 最大0.19ポイントで、参照MAE（4.42〜5.49ポイント）に対して**3.4%以下**である。3次スプラインという柔軟性の高い形を加えても、2020年では改善は0.13ポイントで区間は0を含む。
3. **Pは定数より情報量を持つ。** `constant-mean` はどの年もMAEが8.5〜9.1ポイント悪化し、区間は明らかに0を含まない。`primary-carryover`（Pをそのまま使う）も線形より1.9〜2.5ポイント悪い。**予備選挙の二党得票率そのものが強い説明変数であり、その情報の大半は線形関数の形で捉えられる。**
4. **「複雑なモデルは不要」という結論を採る。** 上記1と2は、独立に採った2022年（探索済み）も含めて3評価年で成立する。**本研究の含意は、モデルを増やすのではなく、適用範囲と不確実性を明示することにある。**
5. **年度効果（バイアス）が主因である。** 2020年は全モデルの平均符号付き残差が−4.2〜−4.6ポイント、2022年は+2.9〜+3.1ポイント、2018年は+0.8〜+1.5ポイントである。**この差はモデルの形ではなく年にある。**[#77](https://github.com/SMRI2170/fec-election-analysis/issues/77) が論じた年度効果の分離と整合する。

### 言えないこと

1. **「非線形モデルに価値がない」とは言わない。** この評価設計（1変数・3評価年・凍結母集団・固定のハイパーパラメータ）では**安定した効果が出ていない**ことに限る。交互作用項や多変量化は本研究の範囲外である。
2. **2022年の最良モデルを予見的な成果とは呼ばない。** 2022年は既に探索で観察済みであり、参照モデルとの差は0.02ポイントで区間は0を含む。
3. **多重比較の補正をしていない。** 12組の比較であり、偶然の出会いを排除できていない。ただし結論（改善がない）は「1組でも大きい改善がある」という主張より弱いので、補正なしでも残る。
4. **母集団は非無作為**（採用率が年・州で異なる）。区間は州クラスターブートストラップによる**探索的**な量である。
5. **ブートストラップの単位を州に選んだのは、地区が独立ではないため**（同じ州の地区は選挙規則と候補者プールを共有する）。この判断は結果を見て決めたものではない。
6. **因果効果ではない。** 票比から政治的な因果効果を示唆しない。
7. **本研究は新しい予測モデルを主張しない。** 比較的目的是「線形1本で十分か」という設計上の問いに答えることである。

## 7. 限界

1. **説明変数はPの1個だけ**で、候補者レベルの特徴量は使わない（[#60](https://github.com/SMRI2170/fec-election-analysis/issues/60) のアブレーションを参照）。
2. **評価年が3つ**であり、順位を安定的に議論できない。
3. **固定のハイパーパラメータ（α=1.0、節点5個、次数3）**で比較しており、モデルごとの最適な α は探索していない。**探索しないことが協議の一部**である。
4. **多重比較の補正なし**、区間は**探索的**。
5. **母集団は非無作為**。
6. **2022年は探索済み**であり、確認的な未知テストではない。
7. **比較した形は限定的**（多項式2次とBスプライン3次のみ）。木モデルや結合モデルは範囲外である。
8. **本研究は新しい予測モデルを主張しない。**
