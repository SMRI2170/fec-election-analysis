# 下院選挙データの正規化設計（Issue #3、第一段階）

## 対象と未対応範囲

確認した2020年・2022年のFEC公式Excelの \`US House Results by State\` シートのみを入力とする。2010〜2018年は**未対応**。モデル性能を優先して都合よくサンプルを選ぶことは避け、全ての除外理由を追跡できるようにする。

- 候補者行をFEC ID（Hから始まる識別子）で特定する。
- \`Party Votes:\` はPrimaryの小計行であり、候補者票と重複合計しない。小計と候補者票の和が一致しない場合は除外する。
- \`District Votes:\` は小計行であり、候補者ではない。
- \`Unopposed\`、Primary票欠損、二大政党候補の片側欠損、0票は補完せず除外。
- 現段階で AK, CA, CT, LA, NY, WA は選挙制度や複数政党記載の個別確認が必要なため保守的に除外する（**州全体の善し悪しの評価ではない**）。
- General runoff / 順位選択投票の結果が含まれるイベントは別途分析が必要なため除外。
- PrimaryとGeneralの二大政党票から、独自の比率を定義する。FEC原表の得票率とは分母が異なる。
- 年度・州・区を同一キーにしても区割り境界は年度で異なる場合がある。異年度の同一地理単位とみなして差分比較しない。

## 実行

\`\`\`bash
python scripts/download_fec.py --years 2020 2022
python scripts/normalize_fec.py --years 2020 2022
python scripts/analyze.py --input data/processed/elections.csv --test-year 2022
\`\`\`

成果物（Git管理対象外）:
- \`data/processed/elections.csv\` — 比較可能と判定した下院区×年レコード
- \`data/processed/exclusions.csv\` — 解析対象から外れた区と理由
- \`data/processed/normalization-summary.json\` — 年別件数と除外理由別内訳

## 確認が必要な論点

1. 抽出後、各年度の収録件数と除外理由を実データで確認し、バイアスを考察する。
2. 2020年AL-01の一次資料の例: Primary R 99,469 / D 52,103、General R 211,825 / D 116,949。元シートの候補者票合計との照合を再実行する。
3. 複数党籍、特殊選挙、無対立選挙と票数の欠損処理は実データで一件ずつ検証する。
4. モデルへの入力特徴量は予測対象より前に確定した情報か検証する。
5. 複数州の除外による代表性低下を定量的に示し、論文中で全米に一般化しない。

この第一段階の変換器は**保守的な暫定実装**であり、すべてのFECデータを忠実に扱えることを意味しない。

この件数は **保守的な機械判定による試行値**。とくに小計不整合123件は、合計の意味・候補者票の記録方法・書き込み投票等を追跡する必要がある。無条件に「データが誤っている」とは言えない。分析に含めることができない理由の可視化であり、統計的代表性は保証していない。

同じAction内で2020年アラバマ州下院第1区を元シートと突合し、共和党Primary=99,469、民主党Primary=52,103、共和党General=211,825、民主党General=116,949が一致したことを確認。

**Issue #3はまだ完了ではない。** この突合は1選挙区だけであり、その他の州・年度の監査、Special Electionの判定、欠損と小計不整合の原因分析が残る。
