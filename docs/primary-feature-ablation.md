# Issue #60 — 予備選挙候補者特徴量のアブレーション

**Issue:** [#60](https://github.com/SMRI2170/fec-election-analysis/issues/60)（親 [#50](https://github.com/SMRI2170/fec-election-analysis/issues/50)）　**依存:** [#59](https://github.com/SMRI2170/fec-election-analysis/issues/59)

**研究の問い:** 凍結母集団の説明変数は予備選挙の共和党二党得票率1個だけである。[#59](https://github.com/SMRI2170/fec-election-analysis/issues/59) が原票から再構成した候補者レベルの特徴量に、**得票率以上の情報価値**はあるか。

**結論（実測）: 得票率を超える安定した情報はない。**5つのモデル群は**どの群も3つの評価年で一貫して改善しない**。効果の大きさは最大0.41ポイントで、符号は年ごとに反転する（例: 候補者数を加えると2018年・2022年は改善するが2020年は悪化する）。**2022年で最良だった群を予見的な成果とは呼ばない**（[#53](https://github.com/SMRI2170/fec-election-analysis/issues/53)で最終評価候補を固定するまで**探索的**である）。

## 1. 事前宣言した比較設計

| 群 | 説明変数 | 学習・検証 |
| --- | --- | --- |
| `p_only` | 予備選挙の共和党二党得票率（**凍結済みベースライン**） | 検証年より前の年のみ |
| `p_candidates` | 得票率 ＋ 両党の候補者数 | 同上 |
| `p_concentration` | 得票率 ＋ 両党の集中度（HHI） | 同上 |
| `p_log_volume` | 得票率 ＋ 両党の規模（log1p総票） | 同上 |
| `p_all` | 上記をすべて | 同上 |

- **両党的特徴量は常に対称に使う。**共和党だけの指標や民主党だけの指標は群に含まれない（`tests/test_feature_ablation.py`で検査）。
- **処理順は `Pipeline` に閉じ込める。**補完（中央値）・標準化・回帰のすべてを**学習年だけで**適合し、検証年の値が変換に混ざらないようにする。標準化は線形モデルの予測を変えないため、`p_only` 群は凍結済みベースラインと**厳密に一致**する（`--assert-baseline`で検証）。
- **比較は同一の検証地区で行う。**全群が各年で同じ件数nを評価する。
- **群は結果を見てから追加しない。**結果は良くなければ良くなかったと報告する。
- **利用不可と判定された特徴量は使わない。**候補者数が下限値しか確定しない地区、無対立で候補者がいない地区は、値を空欄にして**学習年の中央値で補完**する（検証年で補完が要った地区は2020年の2件のみ）。

## 3. 何が言えるか・何が言えないか

**言えること（探索的な記述）**

1. **候補者レベルの特徴量には、得票率を超える安定した情報がない。**同じ群が2020年では改善し、他の年では悪化するという結果は、3評価年で一貫しない。
2. **効果の大きさは小さい。**MAE差の絶対値は最大0.41ポイントで、基準MAE（4.42〜5.49ポイント）に対して1割未満である。**12組中6組で区間が0を含まないが、符号が年ごとに反転するため群の順位は不安定**である。
3. **2022年では集中度を加えると0.41ポイント改善する**（区間[−0.59, −0.21]）。**ただし同じ群は2020年で0.19ポイント悪化する**ため、この改善は**群の選択効果**として扱うべきであり、**予測精度の改善とは主張しない**。
4. **補完が影響するのは2020年の2地区だけ**（議員死亡後の党指名で候補者数が確定しない地区[#59](https://github.com/SMRI2170/fec-election-analysis/issues/59)）。母数から除外していない。

**言えないこと**

1. **「候補者特徴量に情報価値はない」とは言わない。**この設計（1変数線形回帰、3評価年、凍結母集団）では**安定した効果が出ていない**ことに限る。
2. **2022年の最良群は予見的な成果ではない。**2022年は既に探索で観察済みであり、群は結果を見て決めた。
3. **多重比較の補正をしていない。**12組の比較で符号が反転しているため、偶然の出会いを排除できていない。
4. **母集団は非無作為**（採用率が年・州で異なる）。
5. **線形モデルだけを見ており、相互作用や非線形は見ていない。**[#61](https://github.com/SMRI2170/fec-election-analysis/issues/61)・[#62](https://github.com/SMRI2170/fec-election-analysis/issues/62)の非線形比較とは別の切り口である。
6. **因果効果ではない。**

## 4. 再実行手順

```bash
python -m pip install -r requirements.txt
python -m pytest -q tests/test_feature_ablation.py
python scripts/download_fec.py --years 2016 2018 2020 2022
python scripts/normalize_fec.py --years 2016 2018 2020 2022 --writein-policy attribute
python scripts/run_backtests.py --input data/processed/elections.csv --test-years 2018 2020 2022
python scripts/verify_reproducibility.py
python scripts/build_primary_features.py
python scripts/evaluate_feature_ablation.py --assert-baseline
```

出力はGit管理外の `data/processed/feature_ablation/` 配下：`feature_ablation.csv`（群×年×指標）、`feature_ablation_paired.csv`（同一地区の比較）、`feature_ablation_districts.csv`（地区ごとの予測と残差）、`feature_ablation.json`（設定・適合情報・ペア比較）。**地区ごとの明細は公開リポジトリに置かない。**

## 5. 限界

1. **線形回帰1種類だけ**を比べている（[#61](https://github.com/SMRI2170/fec-election-analysis/issues/61)・[#62](https://github.com/SMRI2170/fec-election-analysis/issues/62)は非線形）。
2. **3評価年しかない**ため、群の順序を安定的に議論できない。
3. **多重比較の補正なし**、区間は**探索的**（非無作為な選択集合に依存）。
4. **群は5つで固定**であり、他の組み合わせは試していない。
5. **母集団は非無作為**。
6. **本研究は新しい予測モデルを主張しない。**特徴量群の比較は、**得票率1変数で十分かどうか**という設計上の問いに答えるためのものである。
