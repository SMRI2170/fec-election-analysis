# Issue #14 — Primaryの政党別小計不一致224件の全件監査

検証日: 2026-10-15。一次資料: FEC公式`federalelections{year}.xlsx`（2016・2018・2020・2022）、`US House Results by State`シート。

## 目的と前提

正規化器が`Party Votes:`の政党別Primary小計と、FEC候補者IDを持つ各党候補者のPrimary得票合計が異なる選挙区を除外している。その差の規模・方向・行構成を、**既存の抽出条件を変えず**に独立して集計する。

## 実際の検査結果

[2026-10-15 Actions実行ログ](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38701276417)（Python CIも成功）。

| 対象 | 確認された数値 |
|---|---:|
| 不一致を理由に除外された選挙区 | 224 |
| 2016 / 2018 / 2020 / 2022 | 46 / 55 / 56 / 67 |
| 差がある党別合計（共和党） | 207 |
| 差がある党別合計（民主党） | 189 |
| 党別不一致の総数 | 396 |
| 政党小計が候補者票合計を上回る | 396 |
| 政党小計が候補者票合計を下回る | 0 |
| 差分の中央値 | 216票 |
| 差分の25～75パーセンタイル | 68.75〜561.25票 |
| 差分の最大 | 114,417票 |
| FEC IDなしの**同じ政党コード（R/D）**の行で差が完全に説明される例 | 0 |

**重要:** 「IDなし同じ政党コード行で説明できない」は「差の原因が書き込み票でない」と同じ意味ではない。FEC資料では`Scattered`等の票を`W`などの別コードで記録する場合があり、別の党別集計または票数の処理方法を追加検証する必要がある。

## 元票の代表例

同じ公式Excelから12選挙区（各年度3件）の候補者行・名前・FEC ID・脚注の一部・小計と差分を抽出して保存する。例:
- 2016 AZ-04：民主党の候補者票24,097、小計24,146、差49票。
- 2016 CO-02：民主党の候補者票43,660、小計45,017、差1,357票。
- 2020 AZ-03：共和党の候補者票29,272、小計29,316、差44票。
- 2022 AZ-01：民主党の小計と候補者票差175票。

これらは公式Excel内の**数値差の観察事実**であり、原因は現段階で断定しない。
