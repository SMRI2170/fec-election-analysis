# Issue #14 — Primaryの政党別小計不一致224件の全件監査

検証日: 2026-10-15。一次資料: FEC公式`federalelections{year}.xlsx`（2016・2018・2020・2022）、`US House Results by State`シート。

## 目的と前提

正規化器が`Party Votes:`の政党別Primary小計と、FEC候補者IDを持つ各党候補者のPrimary得票合計が異なる選挙区を除外している。その差の規模・方向・行構成を、**既存の抽出条件を変えず**に独立して集計する。

## 実際の検査結果

|---|---:|

| 差がある党別合計（共和党） | 207 |

| 差分の最大 | 114,417票 |
| FEC IDなしの**同じ政党コード（R/D）**の行で差が完全に説明される例 | 0 |

**重要:** 「IDなし同じ政党コード行で説明できない」は「差の原因が書き込み票でない」と同じ意味ではない。FEC資料では`Scattered`等の票を`W`などの別コードで記録する場合があり、別の党別集計または票数の処理方法を追加検証する必要がある。

## 元票の代表例

同じ公式Excelから12選挙区（各年度3件）の候補者行・名前・FEC ID・脚注の一部・小計と差分を抽出して保存する。例:
- 2016 AZ-04：民主党の候補者票24,097、小計24,146、差49票。
- 2016 CO-02：民主党の候補者票43,660、小計45,017、差1,357票。
- 2020 AZ-03：共和党の候補者票29,272、小計29,316、差44票。
- 2022 AZ-01：民主党の小計と候補者票差175票。

これらは公式Excel内の**数値差の観察事実**であり、原因は現段階で断定しない。

## まだ必要な作業

1. 差のある396政党側について、政党コード`W`・記名/書き込み票・脚注・州別原票表の記載と差の一致を調べる。

4. 未解明の票数を加算せず、保守的な選別済み740件を別ベースラインとして維持する。

**進捗判定: 部分完了。** 差分の全件記録と分布の定量化は成功したが、224件の原因究明は完了していないためIssueはOpenを維持する。

## 第2段階: W(R)/W(D)を考慮した再正規化

公式FECの[2022年PDFのペンシルベニア州の下院選挙結果](https://www.fec.gov/documents/5675/federalelections2022.pdf)では、`Scattered W(R)`や`Scattered W(D)`のPrimary票数が同党の`Party Votes:`小計に含まれている（例: PA-01、PA-02）。この`W(R)`/`W(D)`を一次票に含めるロジックを実装した。ただし、小計と完全一致した場合に限り採用し、他の党派併記等を推測で分割しない。

|年度|修正前の採用|修正後の採用|修正後のPrimary小計不一致除外|
|---|---:|---:|---:|
|2016|169|201|6|
|2018|195|243|5|
|2020|188|237|4|
|2022|186|240|6|
|合計|738|**921**|**21**|

元の224選挙区について、368/396の党側差分は`W(R)`/`W(D)`の合算で説明できた。追加採用可能な選挙区数は、両党別の候補者の存在・票数欠損・公式当選者表示も含む複数条件で決まるため、368を単純に2で割った数にはならない。採用レコードは183件増えた。

**まだ解決していない21選挙区**では、オレゴン州の複数政党表記（例: `D/IP/WF`）等、`W(R)`/`W(D)`以外の要因を考慮する必要がある。候補者票の所属政党を勝手に分配せず、これらは除外を維持する。2016 WY-00では独立した地区総票小計が監査対象テーブル内に見つからず、候補者票計算は一致するが小計検査は要確認。

この処理の結果、採用921件でPrimary/Generalの候補者と党帰属付き書き込み票を考慮した票数不一致0件、公式District General小計を取得できた920件の差異0件を確認した。ただし、これだけで全米代表性が証明されるわけではない。

**研究上の重要性:** 2022年の単純規則 vs ロジスティック回帰の差は、再正規化後にはMcNemar検定p=0.09229となった。採用条件と評価上の結論の関係を[最新のモデル評価](model-evaluation.md)と[感度分析](sensitivity-analysis.md)に記録した。
