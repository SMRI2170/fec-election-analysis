# 予備選挙得票率の確率出力の校正（Issue #64）

**Issue:** [#64](https://github.com/SMRI2170/fec-election-analysis/issues/64)

## 1. 問い

判定保留の研究（#78〜#82）は「どの地区が難しいか」を問うた。本Issueは、その裏側にある問いを扱う。

> **予備選挙得票率から二党票多数派を確率として出力するモデルを、その確率を信頼度として読んでよいか。**

Brierスコアは「確率の精度」を測るが、**校正（calibration）** は別の問いである。
「70%の確率 predicting した地区は、実際に70%正答したか」を問う。校正が崩れている場合、
分類の正解率が高くても確率の数値は信頼度として使えない。

## 2. 方法

- モデル: 既存の年度外バックテストと同一のLogistic回帰（`random_state=0, max_iter=1000`）、
  特徴量は **Primary二党得票率のみ**、目的変数は本選挙の二党票多数派（`general_rep_win`）。
  **新しいモデル種別は導入しない。**
- 学習/検証: 2018は学習200件（2016）・検証241件、2020は学習441件・検証237件、
  2022は学習678件・検証238件。本選挙の二党票同点は評価母数から除外（3年とも0件）。
- 校正表: 予測確率を**固定幅0.1の10ビン**に分割し、各ビンの予測平均確率と観測率を比較する。
  5件未満のビンは `thin` として明示する。
- 指標: Brierスコア、log loss、期待校正誤差ECE（Σ n_b/N × |予測平均 − 観測率|）、
  最大校正誤差、校正の項（平均予測確率 − 観測した正答率）。
- 検証年のGeneral票は**既に固定した予測を採点する用途だけ**に使い、
  モデル・ビン境界・パラメータには一切用いない（`general_used_as_predictor = false`）。
- 多数派規則は確率を出力しないため、本分析の対象外である。

## 4. 報告できる帰結

1. **確率値は信頼度として読めない。** ECE 0.136〜0.187、最大誤差0.297〜0.450は、
   「この模型は70%の確率を出した」と説明できないことを意味する。
2. **ただし本研究の判定保留規則は、校正に依存しない。**
   ロジスティックの係数は正（2018: 6.0516、2020: 8.2756、2022: 9.7183）で、
   予測確率はPrimary二党得票率の**単調変換**である。
   #79の判定保留規則は確率を介さず、
   **整数演算 `100×|R−D| ≧ 2t(R+D)`** でPrimaryの拮抗度から直接定義しており、
   校正の良否に依存しない。保留が効くのは「順序情報」が有用だからであり、
   「確率の数値が正確」だからではない。
3. **出力として妥当なのは多数派規則である。** P>0.5なら共和党優勢という
   0/1の判断は校正の問題を回避できる。確率は補助情報であり、主張には使わない。
4. **2022年の過大予測（校正の項 +0.1044）は、#57の年度差（Primary−General = −2.26ポイント）と
   同じ方向の現象である可能性があるが、本Issueの測定だけでは因果を語れない。**
   断定せず、両者が同じ Sizes であることを記録するにとどめる。

## 5. 限界

1. 単一特徴量（Primary二党得票率）の線形変換であり、より richer な特徴量や非線形モデルでは
   校正が改善する可能性がある。**本Issueでは新しいモデルを試していない**（#61・#62の領域）。
2. 検証は3年のみで、各ビンの標本数は最大79件、最小0件（thin=1ビン、2018年のみ）。
   ビンごとの観測率には標本誤差があり、ECEの絶対値は年をまたいで比較できない。
3. 校正は「二类的多数派」という二値ラベルに対するものであり、
   二党得票率の実数（get票率）を予測する線形写像の誤差（MAE）とは別の量である。
4. FECのワークブックは事後公表であり、Primary得票の事前入手可能性の証明ではない。
5. 多数派規則の「正解」は本選挙の二党票多数派であり、公式当選者ではない。

## 6. 再現

```bash
python -m pip install -r requirements.txt
python scripts/download_fec.py --years 2016 2018 2020 2022
python scripts/normalize_fec.py --years 2016 2018 2020 2022 --writein-policy attribute
python scripts/run_backtests.py --input data/processed/elections.csv --test-years 2018 2020 2022
python scripts/verify_reproducibility.py
python scripts/analyze_probability_calibration.py \
  --input data/processed/elections.csv --test-years 2018 2020 2022
```

出力: `data/processed/calibration/calibration_bins.csv`（年度×ビン）、
`data/processed/calibration/calibration_metrics.json`（年度サマリー）、
`outputs/figures/calibration_reliability.png` / `.svg`（校正図）。
