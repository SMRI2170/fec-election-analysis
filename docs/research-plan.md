# 研究計画（仮説・実験設計）

## 目的
FEC公式データを使い、予備選挙の共和党・民主党別投票数の構成から本選挙の得票比率・勝敗を予測できる条件を調べる。特に、**年度外評価**および**分析対象の選別条件**による変化を比較する。

## 仮説（検証前）
- H1: Primaryの二大政党得票比率とGeneralの得票比率には予測的な関連がある。
- H2: 過去の年度に適合したモデルでも、未使用年度に対する精度が低下する場合がある。
- H3: 無対立選挙や選挙制度の違いを考慮すると、評価対象と予測指標が変化する。

## MVP
1. 原則として下院選挙に限定し、年度・州・選挙区・政党・選挙種別を確認。
2. FEC元データを、年×州×区×選挙イベント単位に正規化。
3. 共和党Primary得票比率 `R_primary/(R_primary+D_primary)` とGeneral比率を作成。
4. 2010〜2020年の比較可能な年度で学習し、2022年で固定評価。
5. ダミー回帰/線形回帰、ダミー分類/ロジスティック回帰を比較。
6. 除外条件を変え、件数・精度・代表性の変化を観察。
7. 誤予測の個別事例を原票まで遡って検証。

## 妥当性の限界
- PrimaryとGeneralは投票者集合が異なるため、割合は党派支持率ではない。
- 選挙制度が異なる州では比較可能性が失われる場合がある。
- 同一選挙区を複数年度で比較する場合、区割り変更に留意する。
- 2022年を調整に使用しない。結論は予測的関連であり、因果効果ではない。
- プロット・数値はFEC実データで検証してからレポートに記載する。
