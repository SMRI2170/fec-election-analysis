# Issue #14：残る21選挙区の複数政党表記とPrimary小計差

検証: 2026-10-15  
データ: FEC Federal Elections 2016 / 2018 / 2020 / 2022 `US House Results by State`  
[公式データによるGitHub Actionsの実行ログ](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38750556721)

## 背景

初期に224選挙区が`primary-subtotal-mismatch`で除外されていた。FECの`W(R)`/`W(D)`（政党帰属付き書き込み票）を正しく加算した後でも、**21選挙区**の党別小計が一致しないまま残った。

今回の`scripts/audit_residual_parties.py`は、各選挙区に対しR/Dの候補者票+帰属付き書き込み票・FEC`Party Votes:`小計を照合する。さらに候補者の`PARTY`列が`D/IP/WF`など**複合コード**を持つ行を抽出し、残差と比較する。

**注意:** 複数政党表記はFECの原票上の事実だが、その票をPrimaryのR/D比率の分子へ算入すべきという証明ではない。この監査は診断であり、現行921件を増減させない。

## 公式原票での検証結果

|検証対象|件数|
|---|---:|
|除外された選挙区|21|
|R/D政党別の検査|42|
|小計と候補者票+帰属付き書き込み票の差が非0|23|
|複合党コードの候補者票と残差の絶対値・符号が完全一致|**18**|
|複合党コードでは説明できない差|5|
|公式の単独政党小計自体がない|3|

21選挙区の年度別内訳: 2016年6、2018年5、2020年4、2022年6。42政党側は、**残差23件 + 小計欠損3件 + 残差0の16件**に分かれる。

## 次に必要な調査

1. **複合党コード18件**: FEC表の党コードの意味、同一候補者の別列での票数記載・重複計上の可能性を確認し、Primaryでどの党の票として数えられるか一次資料で確認する。
2. **5件の残差**: WI-07（2018）、WI-01/WI-02（2020）、UT-02/UT-04（2022）について、党派帰属・候補者ID・選挙方式・脚注を原票と州選管資料で照合する。
3. **小計がない3件**: KS-01（2016）、UT-02・UT-04（2022）のD側を、別候補者の党名表示・無対立・Primary未実施等の記録と照合する。
4. 不一致を安全に解消できない選挙区は引き続き**除外**し、推測によるデータ拡張をしない。

## レポートへの位置付け

重要な研究成果は、政治的な結果そのものだけでなく、**FECのデータ表記をどう正規化するかによって、モデルの訓練対象・評価対象・統計的結論が大きく変化した**点である。現時点で21件の原因が完全に説明できたとは書かない。
