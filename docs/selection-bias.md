# Issue #16: FEC予備選挙データの標本選択バイアスと固定テスト集合の比較

検証日: 2026-10-15  
出典: [公式FECワークブックからの再実行ログ](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38705450847)  
目的: **学習データの拡大による予測変化**と、**評価集合の変化による予測変化**を分ける。

## 比較する前処理条件

- **旧（legacy）**: `W(R)`/`W(D)` の政党帰属付きPrimary書き込み票を加算せず、候補者票合計と政党小計が不一致なら除外する。2018年ME-02とNC-09の公式当選者表示に関する検査は現行と同一。
- **現行（current）**: 同じFEC公式Excelに対し`W(R)`/`W(D)`を対応する党のPrimary票に加え、`Party Votes:`に完全一致する場合のみ採用する。**公式当選者フラグ、その他の除外条件は同じ**。
- 2016・2018・2020・2022年のFEC`US House Results by State`を使用。**2022年を学習に用いない**。

本実験では元のFEC報告にある **1,756個の (年度, 州, 区) グループ**を分母とする。特殊選挙・準州等を含むため、これは**全米の互いに独立した地理的選挙区数ではない**。

## 年度ごとの採用率

|年度|原FECグループ|旧条件の採用|現行の採用|現行の除外|現行採用率|
|---|---:|---:|---:|---:|---:|
|2016|438|169|201|237|45.89%|
|2018|438|195|243|195|55.48%|
|2020|441|188|237|204|53.74%|
|2022|439|186|240|199|54.67%|
|**合計**|**1,756**|**738**|**921**|**835**|**52.45%**|

旧条件は738/1756（42.03%）。同じFEC集計単位に対して、現行基準で**183件**を追加採用した。

除外理由は**優先順位を持つ単一ラベル**であり、除外群の全特徴や制度の重複理由を網羅したものではない。

## 州別の偏り

全4年度のFEC区×年の採用数が0の例: **CA 0/212、WA 0/40、CT 0/20、LA 0/24、AK 0/4**。CA/WA/CT/LA/AKは州制度の保守的な除外のためである。別の州でも無対立・候補者不足などの理由で採用0となるケースがある。

旧条件から採用が増えた主な州はPA（+51件）、WI（+24件）、MA（+22件）、IA（+15件）、AZ（+11件）、IL（+11件）。これは`W(R)`/`W(D)`を無視する旧処理による欠落が、州によって極めて不均一だったことを示す。

**注意:** 採用0の州があるため、現行921件の予測性能を全米の下院選挙区に外挿する根拠はない。Primary票の比較可能性やGeneralとの有権者集団の違いも解消しない。

## 2022年の共通選挙区を固定した比較

次の4通りを比較する:

1. 旧データで学習 → 旧186件で評価
2. 現行データで学習 → 現行240件で評価
3. 旧データで学習 → **共通186件**で評価
4. 現行データで学習 → **同じ共通186件**で評価

③と④のテスト2022年の説明変数と正解ラベルは同一。両方のFEC正規化方式で採用された同一キーの得票数値が一致することをコードで検査し、未来年度は学習へ入れない。

|2022年|学習件数|評価件数|線形回帰MAE|単純多数派規則正解率|ロジスティック正解率|
|---|---:|---:|---:|---:|---:|
|旧→旧|552|186|0.05178|90.86%|85.48%|
|現行→現行|681|240|0.05142|89.58%|86.67%|
|旧→共通186件|552|186|0.05178|90.86%|85.48%|
|現行→共通186件|681|186|0.05210|90.86%|87.10%|

共通186件ではロジスティック回帰の正解率が**約1.61ポイント高い**一方、線形回帰MAEは**0.00032悪化**する。現行の240件での評価では単純規則の精度が90.86%→89.58%となる。これらは**標本の変更によって評価値が変わる**ことの記述的な証拠であって、モデル改良・全選挙区汎化の証明ではない。

## 研究として主張できること・できないこと

- **言えること:** 原票の`W(R)`/`W(D)`の取扱いが採用標本を738→921件へ変え、年度外評価やモデル間の検定結果の解釈も変化した。
- **言えること:** 分母1,756のFEC報告グループにおいて、採用率と理由の分布は州により非常に不均一。
- **言えないこと:** 921件の精度が全国全体の期待精度である、特定州や制度に因果効果がある、今回の差が次の選挙でも再現する。
- **注意:** 2022年を見て特徴量や閾値を選ぶ場合は探索的解析とし、独立な検証結果と区別する。

## 次に残る課題

- FECの原票で観測できる欠損/除外群の競争度など、比較できる範囲の追加診断。
- 2016年WY-00の地区General総票の独立小計は欠けており、別途検証が必要。
- Issue #14の残る21件のPrimary小計差の一部は複数政党表記等によると考えられるが、安易に採用しない。
- Issue #17の個別誤予測例では、採用群に偏りがあることを踏まえ、原因の因果的断定を避ける。

この研究の中心結果は「前処理によって予測の統計的結論が変わり得ること」だが、**原因が書き込み票の扱いに限定される範囲と、それ以外のサンプル選択による差を分けて説明する**。

## 追加検証：除外群で観測できる得票情報（Issue #16、2026-10-16）

[実FECデータ監査（全1,756グループ）](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38849363678) により、採用／除外群の**もともとの原票セル**を再調査した。

|原票から観測可能な項目|採用群（921件）|除外群（835件）|
|---|---:|---:|
|PrimaryのR/Dそれぞれの`Party Votes:`小計が数値で取得できる|921|68|
|GeneralのR/D候補者票が両方とも数値で取得できる|921|577|

Primaryについては候補者票からの欠損補完を行わず、**FECの公式Party Votes小計が各党1つずつ存在して数値である場合のみ**「観測可能」と判定する。Generalは数値が入ったR/D候補者行だけを使用し、空欄・`Unopposed`などの非数値欄をゼロとして埋めない。両党候補者票の数値がそれぞれ一つ以上ある場合に限り、観測値から二大政党得票比率および得票差を計算する。

このため、除外群835件のうち577件にはGeneralの得票情報が残るが、68件にしか**両党の公式Primary小計**をそのまま取得できない。これらの条件は、元の正規化に必要な党別得票・候補者・制度の条件をすべて満たすわけではない。**68件をそのまま追加採用できるとは主張しない**。

この追加検証は選挙後の**診断**であり、Generalの得票数・得票差を予測時の入力特徴量として学習・推論に渡さない。また、除外群の観測可能な一部だけを比べても、除外された全グループの競争度を推定したことにはならない。

### 再現

```bash
python scripts/download_fec.py --years 2016 2018 2020 2022
python scripts/normalize_fec.py --years 2016 2018 2020 2022
python scripts/audit_selection_observability.py
```

Git管理対象外の成果物は `data/processed/selection-observability.csv`（全FECグループの元票・欠損区別・採否）、`selection-observability-summary.csv`（年度・除外理由別）、`selection-observability-meta.json`（全体の観測可能件数と競争度統計）。GitHub Actionsが生成する。観測可能なGeneral得票差の中央値は、元ファイルで両党の数値行がある対象に限定して記述し、採用群との単純な比較を全米の選挙競争度の比較と取り違えない。
