# Issue #78 — 判定保留実験の評価母数と基準24誤答を厳密に再現する

**状態:** 新規検証（#76-A）。判定保留の実験の前に**評価母数を凍結**する。既存916件のデータ・予測指標は**更新しない**。

## 何を検証するか

判定保留（abstention）の実験は、回答率（coverage）を上げたことで正解率が上がったように見えると批判されやすい。この混乱を防ぐには、**保留実験が使う母数と、保留規則が一切参照してはならない information** を先に固定する必要がある。

本Issueは次の4点を実測で確定する。

1. **(year, state, district) キー**が1つの下院選区を1意に定めること。
2. 票数列が非負整数で、二党票合計が正であること。
3. **3つの分母を混ぜないこと**: 公式FEC報告グループ1,756件／そのうち50州Voting House 1,734件／実際に評価できる916件。
4. 保留閾値t=0（全件判定）で、既存バックテストの**誤答24/24/24・正解率90.04/89.87/89.92%**を1桁も違わずに再現すること。

## 母数の包含関係（別分母として扱う）

|分母|件数|意味|
|---|---:|---|
|公式FEC報告グループ|1,756|4年度ワークブックのHouse報告グループ全件|
|50州Voting House報告グループ|1,734|1,756から非投票権Delegate法域22件を除いたもの|
|評価に採用できる916件|916|1,734のうち保守的正規化を通過した選別標本|

**916/1,734 = 52.83%** は「分析に採用できた割合」であり、**「予測できる選挙区の割合」ではない**。この3つの分母は本研究全体で混用しない。

非投票権Delegate法域（AS/DC/GU/MP/PR/VI）の22件は、50州分母にも**全国分母にも入れない**。

## 情報分離の明確化

|情報|使用目的|保留判断への使用|
|---|---|---|
|Primary R/D得票|Pの計算とマージン`\|P-0.5\|`|**使う**|
|General R/D得票|凍結済み予測の採点のみ|**使わない**|
|公式当選者|916件のラベル整合監査のみ|**使わない**|

「二党票多数派」と「公式当選者」は別物であり、本Issueのラベル`general_rep_win`は**二党票多数派**を指す。

## 実装物

- `src/fec_analysis/selective.py` — 母数契約の**唯一の情報源**（固定定数・母数選択・ベースライン採点・監査）。
- `scripts/inspect_selective_cohort.py` — 監査CLI。契約違反時は**終了コード1**を返すため、CIが黙って通らない。
- `tests/test_selective_cohort.py` — 合成fixtureによる単体テスト17件。実FEC数値はCIで検証し、fixtureと混ぜない。
- `.github/workflows/selective-cohort-audit.yml` — 公式FECを再取得して**SHA-256・916件・24/24/24誤答**を再検証する専用CI。

## 再実行

```bash
python scripts/download_fec.py --years 2016 2018 2020 2022
python scripts/normalize_fec.py --years 2016 2018 2020 2022 --writein-policy attribute
python scripts/inspect_selective_cohort.py --output data/processed/selective-cohort-audit.json
```

監査レポート：`data/processed/selective-cohort-audit.json`（期待値と観測値を対で保持し、どの契約が壊れたか特定できる）。

## 限界

- 916件は**本選挙後に確定した選別標本**であり、選挙前に予測可能な地区の無作為標本ではない（[#49](https://github.com/SMRI2170/fec-election-analysis/issues/49)）。
- FECの最終公刊ワークブックから**事後的に再構成**した値であり、選挙前運用精度を示さない。
- 本Issueは**母数の凍結のみ**であり、判定保留の効果はまだ測定していない。保留規則は[#79](https://github.com/SMRI2170/fec-election-analysis/issues/79)で実装し、15条件評価は[#80](https://github.com/SMRI2170/fec-election-analysis/issues/80)で行う。
