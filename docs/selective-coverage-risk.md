## Findings

### F1. 保留時の条件付きriskは3年すべてで単調に低下した

t=0→20で条件付き誤り率は 2018: 9.96%→0.00%、2020: 10.13%→0.00%、2022: 10.08%→0.00%。**H1（拮抗度の高い Primary 二党比率の地区に誤りが集中する）は支持された**。

事前仮説 **H2（改善は年度ごとに異なり単調とは限らない）は観察されなかった**。3年すべてで単調改善している。ただし2022年の得票率帯別誤答分析を**先に読んでから**立てた仮説なので、これは独立した確認的証拠ではない。

### F2. 改善の代償は回答率に出る

同じ改善のために放弃了正答は 2018 t=20 で**122件**、2020 t=20 で**117件**、2022 t=20 で**91件**。回答率は 39.42% / 40.51% / 51.68% まで落ちる。

つまり「100%の地区に90%の精度」に対し「40%の地区に100%の精度」という**トレードオフ**であり、精度だけを見れば改善に見える。**回答範囲を必ず併記する。**

### F3. 保留を正解に数えなくても誤答率は下がる

`wrong_per_eligible`（回答した誤答を全母数で割った値、保留を正解として加算しない）は 2018: 9.96%→0.00%、2020: 10.13%→0.00%、2022: 10.08%→0.00% と低下する。ただしこれは**母数そのものが縮んでいる**ことの帰結であり、比較の不公平さは避けている。

### F4. 保留した誤答も記録した

t=20では 2018: 24件、2020: 24件、2022: 24件 — つまり**全24件の誤答が保留に回された**。誤答が完全に消えたのではなく、回答対象から外れただけである。2018 t=15 では誤答2件が残存し、2020 t=15 / 2022 t=15 では0件だが、正答を93件 / 91件 / 60件放棄している。

## まだ答えられていない問い（重要）

**このIssueの結果だけでは「Primary の拮抗度は誤答を識別する情報になる」とは言えない。** 保留すれば誤答が減るのは自明である。 同数のランダム保留したときの期待誤答（K·E/N）との比較は[#81](https://github.com/SMRI2170/fec-election-analysis/issues/81)で行う。上の表が「-random より良い」ことを示すまでは、主張は**保留による見かけの精度向上**の可能性がある。

> **更新（[#81](https://github.com/SMRI2170/fec-election-analysis/issues/81)で回答済み）:** 同数のランダム保留との比較の結果、**t>0の全12条件**で観測誤答数がランダム期待値を7.75〜15.53件下回り、ランダム保留の5パーセンタイル未満となった。すなわち拮抗度は**同数ランダム保留より明らかに多く誤答を排除する**。ただし回答率40〜52%という代償は残る。詳細は[同Issueのノート](selective-random-baseline.md)。本Issueの集計表自体は変更していない。

## 実装と検証

- `scripts/evaluate_selective_primary.py` — 15条件の評価器。`evaluate_grid()` がCSV/JSONを生成し、`check_baseline()` と `check_monotonicity()` が契約を検証する。違反時は終了コード1。
- `tests/test_selective_primary.py` — 合成fixtureの単体テスト19件。保存則、General票不変性、同点除外、acceptedの単調非増加、accepted=0でのNA。
- `.github/workflows/selective-primary-analysis.yml` — 公式FEC再取得→SHA-256→正規化→母数監査→15条件評価→ベースライン固定検証→pytest→Artifact。
- 出力: `data/processed/selective-primary-grid.csv`（15行）、`data/processed/selective-primary-grid.json`（定義・検査結果つき）。

保存則（CIでも検証）: `accepted + abstained = eligible`、`correct_accepted + wrong_accepted = accepted`、`correct_abstained + wrong_abstained = abstained`、`wrong_accepted ≤ accepted`。

## 限界

- 916件は**本選挙後に確定した選別標本**。無作為標本ではなく、選挙前の可用性も未証明（[#49](https://github.com/SMRI2170/fec-election-analysis/issues/49)）。
- 2022年の得票率帯別誤答を**先に読んだ後に**設計を確定しているため、**全結果は探索的**である。
- 閾値は固定済みだが、5点刻みの**粗い格子**であり、最適閾値を探索していない。
- 複数比較（3年×5閾値）であり、有意性の主張はしない。
- 保留は「回答しなかった」ことであり、**運用上の無害ではない**。全米の選挙区数で40%の回答率では実用の予測手段にならない。
- 既存916件・既存バックテスト指標は変更していない。general_rep_win は二党票多数派であり公式当選者ではない。
