# Issue #81 — 同数ランダム保留との比較と不確実性の限界

**状態:** 新規検証（#76-D）。[#80](https://github.com/SMRI2170/fec-election-analysis/issues/80)の15条件に、**同数のランダム保留**を仮定したときの参照値として追加する。

## なぜこの比較が必要か

保留すれば誤答が減るのは**自明**である。「回答した地区の誤答率が下がった」だけでは、保留した地区が何だったかに依存するため意味を持たない。問うべきは次の1点である。

> **Primary二党得票率の拮抗度は、「予測が難しい地区」を識別する情報になるか。**

これを検証するため、同じ年度・同じ閾値で**回答数Kが同じ**ランダム保留を仮定し、そのときの誤答数を参照値とする。

## 参照モデル

- `N` = その年の評価母数、`E` = t=0（全件判定）の誤答数、`K` = その閾値での回答数。
- N件からK件を**一様無作為に**選んで回答し、残りを保留したとき、回答中の誤答数 X は超幾何分布に従う:

  X ~ Hypergeometric(N, E, K)、期待値 = K·E/N、分散 = K·(E/N)·(1−E/N)·((N−K)/(N−1))

- 観測値との差 `error_avoidance_vs_random` = (K·E/N) − 観測誤答数。**正ならランダム保留の期待より良い**。
- 実装は `math.comb` による厳密整数演算でPMFを計算し、**scipy非依存**。scipy `hypergeom.pmf` と一致することを開発時に照合した（開発環境のみ、CIの要件には含めない）。

## Findings

### F1. 拮抗度は誤答を識別する（12/12条件）

t>0の**全12条件**で、観測誤答数はランダム保留の期待値を**下回り**、差（回避）は **+7.75件〜+15.53件**。さらに観測誤答数はランダム保留の**5パーセンタイル未満**（例: 2018 t=5 は 観測11件 vs 5%点17件、2022 t=15 は 観測0件 vs 5%点12件）。

つまり Primary二党得票率の拮抗度は、**同数のランダム保留より明らかに多く誤答を排除する**。保留による見かけの精度向上ではない。

### F2. 除外された誤答の帰結ではなく、選択能力がある

この結果は「保留した分だけ誤答が減る」という自明な効果ではない。**同じ回答数K**のランダム保留	Expected通り≈9〜21件**の誤答が残る**のに対し、規則は0〜12件しか残さない。

### F3. ただし代償は大きい

回避できた誤答は最大15.53件/年だが、そのために**91〜122件の正答を保留**している。回答率は40〜52%まで落ちる。精度改善と適用範囲の縮小は**トレードオフ**であり、どちらも併記する。

### F4. 多重比較の限界

3年×5閾値=15条件の比較は**探索的**である。Bonferroni補正（12条件、α=0.05 → 0.00417）を単純に適用しても全条件が p < 0.00417 を満たすため、**この比較の結論は多重比較に対して頑健**と述べられる。ただし設計全体を探索的とする理由（[#76](https://github.com/SMRI2170/fec-election-analysis/issues/76)で2022年の得票率帯別誤答分析を**先に読んだ**後に仮説と閾値を確定した）は消えない。

## 不確実性の限界（明記）

- ランダム保留は**参照点**であり、「保留した地区が無作為に実施された」ことを意味しない。
- 超幾何分布は**誤答数のみ**をモデル化しており、地区間の他の相関を無視している。
- `p_random_at_least_as_good` は**探索的**であり、「有意に優れた新手法」という主張には使わない。
- **保留は正解でも誤答でもない。** `correct_abstained` を全行に併記し、恣意的な最良閾値は選ばない。
- 全12条件でランダムより良いが、**回答率40%という実行可能性は別に評価すべき**である。
