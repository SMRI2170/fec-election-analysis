# Issue #79 — Generalを参照しない判定保留純粋関数

**状態:** 新規実装（#76-B）。判定保留の**判断だけ**を行う純粋関数を固定する。実データでの評価は[#80](https://github.com/SMRI2170/fec-election-analysis/issues/80)以降で行う。

## 設計上の要点

判定保留の判断は、**Primaryの得票数2個と事前固定した閾値だけ**から決められる。General票・Generalの正解ラベル・年度・学習済みパラメータは、関数のシグネチャに**存在しない**。

```python
selective_rule(primary_r: int, primary_d: int, threshold_pct: int) -> tuple[bool, int | None]
```

- `threshold_pct` はPrimary二党得票率のマージン（**パーセンテージポイント**）。許されるのは **0 / 5 / 10 / 15 / 20** のみ。
- `P = primary_r / (primary_r + primary_d)`、`margin = |P − 0.5|`。
- 回答条件は**整数演算**で判定する: `100 * |R − D| >= 2 * t * (R + D)`。
- 回答したとき `R > D` なら `1`（共和党二党優勢）、それ以外は `0`（民主党二党優勢）。**Primary同数（`R = D`）は `0`（D優勢）と予測**し、既存 `primary-winner rule` に揃える。
- 保留したとき答えは `None`。**保留は正解でも誤答でもない**。

## 整数演算不能不浮動小数点を使う理由

`t=10`・`R=2, D=3` のとき、境界はちょうど10ポイントなので仕様どおり**回答**する。

```
Fraction: |2/5 − 1/2| = 1/10 >= 1/10   -> True（厳密）
float:   |2/5 − 0.5| = 0.09999999999999998 < 0.1 -> False（誤判定）
```

浮動小数点では境界で誤判定するため、採否は票数の整数演算で決めている。`tests/test_selective_primary_rule.py` では `Fraction` で厳密一致を検証し、浮動小数点が境界で誤ることも明示的にテストしている。

## 境界の定義

|閾値|保留するPrimaryのR二党得票率|45/55・55/45は|
|---|---|---|
|0pt|なし（保留しない）|回答（`R=D`も回答してD優勢）|
|5pt|45%より大きく55%より小さい|**回答**（R46/D54は保留）|
|10pt|40%より大きく60%より小さい|回答（R41/D59は保留）|
|15pt|35%より大きく65%より小さい|回答（R36/D64は保留）|
|20pt|30%より大きく70%より小さい|回答（R31/D69は保留）|

区間端は**回答**する（`>=`）。`R = D` は t>0 では保留、t=0 でのみD優勢として回答する。

## 不正入力の扱い

|入力|結果|
|---|---|
|票数0（片側100%になる入力）|`ValueError`。無対立Primaryは選別段階で除外されており、100%の得票率は存在しない|
|負の票数|`ValueError`|
|小数票数|`TypeError`|
|`bool`|`TypeError`（`True` は票数ではない）|
|未登録の閾値（1, 2, 10.0, 25, -5, None, "5"）|`ValueError` / `TypeError`|
|非常に大きい票数（10^30）|オーバーフローしない（Pythonの任意精度整数）|

## 検証

`tests/test_selective_primary_rule.py`（38件、合成入力のみ）:
- 5閾値すべての境界値（45/55、46/54 等）
- Primary同数（`R=D`）の挙動
- 票順転倒（R/D入れ替え）で判断が同じ・答えだけ反転すること
- 整数式と厳密有理数定義の一致（1..59 × 1..59 × 5閾値の全組合せ）
- 浮動小数点比較が境界で誤ることを明示
- 不正入力の拒否
- **General票・General正解ラベルを変更しても判断が一切変わらない**ことの検証（シグネチャにGeneral系引数が存在しないことも確認）

実データでの確認（[#78](https://github.com/SMRI2170/fec-election-analysis/issues/78)の母数）:
t=0 の規則出力が既存 `primary-winner rule` と**全716行で完全一致**（不一致0件）。
