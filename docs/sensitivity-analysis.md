# 感度分析と誤予測の検証 — 計画・初回評価（Issue #5）

## 研究上の目的

Issue #4では2016〜2022年の選別済み740レコードから高い正解率を得た。しかし、含まれる選挙区が変わると数値が変わる可能性がある。本実験は**標本選択への感度**と**予測誤差が大きい選挙区**を調べる。

## 実験A: Primaryの党別投票数に関する感度

元の正規化条件は変更せず、両党のPrimary投票数がそれぞれ 0 / 1,000 / 5,000 / 10,000 票以上という4つの下限を追加する。

- 学習はテスト年度より前の選挙のみ。
- 各条件で学習・テスト件数、MAE、accuracy、Brierを記録する。
- 条件を厳しくしたとき精度が変わっても、それは**異なる標本での比較**であり、モデル改善とは限らない。
- 2022年で最適な閾値を選んでから「事前に設定した」とは主張しない。探索的分析として区別する。

## 実験B: 予測失敗事例

2016・2018・2020年のデータで線形回帰/ロジスティック回帰を学習し、2022年の選別済み選挙区で予測を行う。

- 線形回帰の共和党得票比率の絶対誤差で降順に並べる。
- Primary多数派の単純規則とロジスティック回帰の勝敗予測ミスも併記する。
- 候補者の所属・無対立・州制度・Special Election・票数の転記等が原因とは**原票の検証前には判断しない**。

この閾値範囲ではMAEの変化は小さかった。ただし、10,000票条件では11選挙区がテスト母集団から外れたため、同一サンプル上での純粋な比較ではない。元の除外条件（特殊な州制度、無対立、Primary票小計の不一致等）の頑健性を保証するものではない。

2022年の評価対象186選挙区について、Primary多数派規則は**17件**、ロジスティック回帰は**28件**の勝敗誤判定だった。

**次の課題:** 上記の選挙区をFEC原票で照合し、特殊な候補者・選挙制度・書き込み票や票数転記が関与していないか検証する。単純なロジスティック回帰の誤判定増加についても、判別閾値と学習年度の違いを考慮して解釈する。検証前に因果的な説明を付けない。

## 2022年の勝敗予測差に関する探索的な検定

[実データでのペア対応検定ログ](https://github.com/SMRI2170/fec-election-analysis/actions/runs/38690181698)。Primary多数派による単純勝敗判定は169/186件（90.86%）、ロジスティック回帰は158/186件（84.95%）で正しかった。差は**5.91ポイント**。

- McNemar正確両側検定: **p = 0.00341796875**
- 選挙区を独立サンプリング単位とみなすペアブートストラップ（10,000回）の95%区間: **[+2.69, +9.68]ポイント**。
- 州内の相関を考慮するため、州単位のクラスター再標本化による補助的区間も実装した。結果は再実行ログで確認する。

**注意点**: 選挙区間の依存関係や州レベルの関連、また複数の探索的比較による選択の影響を受ける。検定結果だけから一般的な優劣や2024年以降の予測性能は主張できない。この差は今回選別した2022年レコードについての記述的・探索的結果である。

2022年の誤差上位5件はFECの候補者票・地区総票に直接照合され、**元Excelとの数値整合が確認された**。ただし、誤差が大きい政治的原因は判定していない。詳しくは [原票照合の記録](source-reconciliation.md)。
