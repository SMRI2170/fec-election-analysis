# 州×年度の符号付き残差の構成効果と標本数（Issue #63）

**Issue:** [#63](https://github.com/SMRI2170/fec-election-analysis/issues/63)
**前提:** [#57](https://github.com/SMRI2170/fec-election-analysis/issues/57)（PR #73、mainへマージ済み）

## 1. 問い

#57 が報告した「年度ごとの符号付き残差（pred − actual）」は、**採用された地区を1件ずつ重み付けして平均した1つの値**である。
この値はどの州がどれほど外したのかを隠す。次の3点を監査する。

1. その年度値の符号は、**比較可能な州（n≥5）**と**比較不可能な州（1≤n<5）**のどちらが動かしているか。
2. 比較不可能な州に含まれる地区は全体の何％で、残差の何％を担っているか。
3. 比較可能な州の中に、年度値と**逆符号**の州がいくつあるか（構成効果の直接証拠）。

**新しい予測モデルは作らない。** #57 の `analyze_state_year.py` が出力した
`state_year_error_metrics.csv` と `state_year_coverage.csv` をそのまま監査する。

## 2. 方法

- 対象年: 2018・2020・2022（年度外線形回帰の検証年）。学習年は前年度まで。
- 州を3群に分割する。**n≥5**（記述的に州比較が可能な州）、**1≤n<5**（採用はあるが州比較には足りない州）、**n=0**（採用0件の州）。
- 符号付き残差 `linear_signed_pred_minus_actual` は地区ごとに符号を保持したまま扱う。
  *年度値* = Σ(n_i × s_i) / Σ n_i（地区等重み）。
  *群の寄与率* = Σ(n_i × s_i) / Σ(n_i × s_i)（全体に対する符号付き偏りの割合。符号が反転しうるため100%を超えることがある）。
- 検証年のGeneral票を入力・パラメータに用いない（`general_used_as_predictor = false`）。

## 3. 結果（実測）

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

### 3.1 2018年：年度値はほぼ相殺の結果である

2018年の年度値は +0.0077 と小さいが、これは **n≥5の16州が +150.96%（符号付き偏り +2.80）**、
**n<5の21州が −50.96%（−0.95）** の**差**である。
比較可能な16州が同一方向に動くなら年度値は約 +0.014 になるはずで、
小さい州群が符号を逆向こうすることで年度値は半分以下に押さえられている。
さらに、比較可能な16州のうち **2州は年度値と逆符号**である。

### 3.2 2020年：年度値の符号は全群で一致する

2020年は n≥5の16州（−81.14%）と n<5の21州（+18.86%）が同符号で、
年度値 −0.0458 はほぼ n≥5の群がそのまま決めている。
逆符号の比較可能州は1州のみ。

### 3.3 2022年：年度値は n≥5の群にほぼ完全に由来する

2022年は n≥5の17州が +96.08%、n<5の19州が +3.92%。
年度値 +0.0300 は n≥5の群の値 +0.0340（平均州符号付き残差）に近い。

### 3.4 標本数：毎年の5分の1が「比較できない州」にある

比較可能な州（n≥5）に属する地区は 78.01% / 80.17% / 82.35%。
残る **42〜53件（17.65〜21.99%）** は n<5 の州にあり、
これらの州は州別の誤差・偏りを記述できない。
n=0 の州は毎年13〜14州で、採用が0件である。

## 4. 報告できる主張とできない主張

**できる:**
- 年度ごとの符号付き残差は、**比較可能な州とそうでない州の合成**であり、年度値の符号は「その年の共和党の優勢」を直接表すものではない。
- 2018年では年度値が小さく見えるのは符号の相殺の結果であり、比較可能な州だけでは約2倍の値になる。
- 毎年の5分の1に近い地区は州別比較の可否を欠き、州別ランキングは地域的な適用範囲を保証しない。

**できない:**
- 州ごとの優劣や「某些州で予測しやすい」という主張（n<5の州は記述対象から除外している）。
- 年度差を政治的・制度的な原因に結びづけること（投票者集団・制度・学習年はいずれも交絡している）。
- n=0の13〜14州について誤差を語ること（分母0）。

## 6. 限界

1. 本監査は #57 の残差を分解したものであり、**新しい推定量を追加していない**。州ごとの残差の推定方法（線形写像の年度外学習）は #57 の定義に従う。
2. 符号付き残差は予測側の符号を保持するため、MAEとは別の量であり、两者を一つの指標として比較しない。
3. 群の寄与率が100%を超えるのは符号が群間で反転するためであり、異常値ではない。
4. 州は毎年同じ区割りとは仮定しない（#57の限界）。
5. n<5の州を「除外した規模」は、選択の是非を論じるものではなく、**記述的可能性の境界**である。採用そのものは #57 の選定規則に従う。
