# Issue #65 — 州を学習から除いた外挿ストレステスト

**Issue:** [#65](https://github.com/SMRI2170/fec-election-analysis/issues/65)（親 [#52](https://github.com/SMRI2170/fec-election-analysis/issues/52)）

**研究の問い:** [#57](https://github.com/SMRI2170/fec-election-analysis/issues/57) が示した「州ごとの予測難度の差」は、その州自身の過去の選挙データ第四条を学習に含めていることに由来するのか。**各テスト年・各テスト州について、その州を学習から完全に除いたモデルと通常のモデルを、同じテスト地区・同じ指標で比較する。**

**結論（実測）: 州の違いは、その州自身の学習データにほとんど依存しない。**除外によるMAE変化の中央値は**+0.015ポイント**で、105組中68組がわずかに悪化するが、絶対値が0.2ポイントを超えるのは8組だけである。**本研究の1変数線形モデルは州固有のパラメータを持たない**ため、[#57](https://github.com/SMRI2170/fec-election-analysis/issues/57)の州別の差 disfavored は**モデルの容量ではなくデータの構造の記述**である。

## 1. 実験の設計

| 項目 | 内容 |
| --- | --- |
| 母数 | 凍結済みの50州Voting House **916件**（200/241/237/238） |
| 評価年 | 2018・2020・2022 |
| 通常モデル | 評価年より前の年すべての採用地区で1変数線形回帰（説明変数＝予備選挙の共和党二党得票率） |
| 除外モデル | 同じ学習年から、**対象州 s の地区をすべて除いて**再学習 |
| 比較対象 | **同一のテスト地区**：評価年の州 s の地区のみ |
| 指標 | MAE、`RMSE`、平均符号付き残差（予測−実測）、予測値の変化量、州 s の学習件数と削減率 |
| 対象州 | 各評価年に採用地区が存在する州すべて（2018年37州・2020年37州・2022年36州） |
| 除外できない場合 | 州 s に学習年の地区が1件もない場合、**除外による変化は0**として記録し、欠落扱いにしない |

## 3. 何が言えるか・何が言えないか

**言えること（探索的な記述）**

1. **この1変数線形モデルの予測は、対象州自身の過去の選挙データにほとんど依存しない。**[#57](https://github.com/SMRI2170/fec-election-analysis/issues/57)が示した州ごとの予測難度の差は、**モデルが州固有のパラメータを持たないことの帰結**であり、州ごとの学習データ量の差の帰結ではない。
2. 除外の効果は105組中68組で悪化したが、中央値は0.015ポイントと小さい。改善した組も37組あり、**方向は両側に散らばっており、除外が常に損をするわけではない。**
3. **除外できない5組を明示的に記録した。**学習年にも採用地区がない州は「変化ゼロ」であり、欠落ではない。

**言えないこと**

1. **州依存性がないことを示すものではない。**2パラメータのモデルでは、そもそも州ごとの情報を表达できない。候補者数など州ごとに異なる説明変数を加えれば、依存性の強さは変わる（[#59](https://github.com/SMRI2170/fec-election-analysis/issues/59)・[#60](https://github.com/SMRI2170/fec-election-analysis/issues/60)）。
2. **州ごとの差の原因を特定していない。**[#63](https://github.com/SMRI2170/fec-election-analysis/issues/63)の州構成の寄与分析とは別の切り口であり、本Issueは州別差の**原因**を追わない。
3. **1〜3件のテスト地区を持つ州は行ごとに不安定**である。行ごとの差を州の評価点として読まない。
4. **州は独立ではない。**政党・メディア・候補者プールを共有し、地理的にも隣接州の影響を受ける。州単位のブートストラップはこの非独立性を踏まえたものであって、除去したものではない。
5. **評価年は既に探索で観察済み**であり、確認的な保留試験ではない。
6. **因果効果ではない。**

出力はGit管理外の `data/processed/unseen_state/` 配下：`unseen_state.csv`（州×年の集計110行）、`unseen_state_summary.json`（集計サマリー）。**区ごとの明細は出力していない**（州×年の集計のみ）。

## 5. 限界

1. **単一変数モデル**であり、候補者数など他の変数を統制していない。
2. **除外の影響が小さくなる構造**（2パラメータ、削減率1〜2%）を直接測定しているのであり、州依存性のないことの証明ではない。
3. **小さいテスト地区の州**（110組中51組が3地区以下）は行ごとの差が不安定。
4. **州は独立でない**ため、州単位の集計は集約的な記述に限られる。
5. 母集団は非無作為（採用率が年・州で異なる）。
6. **本Issueは新しい予測モデルを主張しない。**発展的な診断である。
